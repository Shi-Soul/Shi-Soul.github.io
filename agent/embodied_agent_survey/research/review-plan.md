# Geometric Abstraction 增补记录

本次增补回答一个问题：机器人把实时几何信息交给语言模型后，策略编写和在线操作有什么变化？读者是需要了解语言模型机器人接口的机器人研究者。

核对日期为 2026-11-05。收录对象为用户指定的 Geometric Abstraction，使用 arXiv:2611.05058v1、官方项目页面、代码仓库和 arXiv API 元数据。原综述的全领域检索日期保留为 2026-10-23。

比较两组获得的输入和接口，并分别记录离线策略编写、在线连续执行的设置。结果按任务记录成功次数、限时平均用时、模型调用时间和词元用量。正文采用论文第 3 至 5 节及附录 B、表 3 的结果，在线任务每项有 50 组配对布局。

论文列表归入“代码即策略”“运行接口”和“规划器”三个现有类别；正文在第 2.2 节介绍两种执行方式，第 2.6 节解释几何接口和在线结果，时间线记录 2026-11-03 首发。

`source-ledger.csv` 记录四个来源，`claim-evidence-matrix.csv` 记录五项论述及对应原文位置。这两份记录覆盖本次增补。网页与长文由现有构建程序生成，再同步到网站仓库的 `agent/embodied_agent_survey/`。
