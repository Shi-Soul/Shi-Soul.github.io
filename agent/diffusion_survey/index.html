扩散模型与流匹配：从原理到 2026 前沿

扩散模型与流匹配是今天图像、视频、音频、3D 乃至一部分语言生成背后的主流方法。本页先用一套统一的数学语言讲清它们是什么、为什么本质相同，再梳理十条技术路线、最近一年（2025-10 → 2026-10）的关键进展、模型版图、评测方法与上手路线。

一页看懂

一句话：扩散模型和流匹配都在学一个"速度场"，它把一团高斯噪声一步步搬运成数据。十年来的进展，几乎都可以归到四个问题上：搬运路线怎么设计、搬运能不能更快、用什么空间和网络来搬、搬出来的东西怎样更合人意。

2015 → 2020

奠基

Sohl-Dickstein 提出"逐步加噪、学习还原"；NCSN 学习分数；DDPM 把训练化简为"预测噪声"；Score SDE 统一到连续时间，给出概率流 ODE。

2021 → 2022

文生图爆发

ADM 超越 GAN，CFG 成为标配；LDM 在潜空间扩散催生 Stable Diffusion；DALL·E 2、Imagen 问世；DDIM、DPM-Solver 把步数降到几十；流匹配与 Rectified Flow 提出。

2023 → 2025-09

Transformer 化与规模化

DiT 取代 U-Net；SD3 与 FLUX.1 把流匹配推向大规模；Sora 打开视频；一致性模型、DMD 带来少步生成；REPA 加速训练；Flow-GRPO 把 RL 带进流模型；LLaDA 让扩散进入语言。

2025-10 → 2026-10（最近一年）

一步、像素、后训练、世界

从头训练的一步生成追上多步（iMF、Drifting、Priming）；VAE 被重新设计甚至抛弃（RAE、JiT）；RL 后训练成标配（DiffusionNFT）；音视频联合与实时世界模型（Seedance 2.0、Genie 4）；扩散 LLM 扩展到 100B（LLaDA2.0）。

七个结论

  1. 扩散与流匹配本质上是一回事。二者都在学"把噪声搬运成数据"的时间相关向量场，差别主要在噪声路径、预测目标（噪声 / 数据 / 速度）与时间加权。2024 年以后的大模型（SD3、FLUX、HunyuanVideo、Wan、Qwen-Image…）几乎都用"流匹配 + 速度预测 + DiT"这一组合。
  2. 速度问题基本有了答案。蒸馏（DMD2、rCM、Decoupled DMD）让工业模型 4–8 步出图；最近一年"从头训练的一步模型"把 ImageNet 一步 FID 推到 1.2–1.7，与多步模型进入同一量级。
  3. 潜空间正在被重新设计。"先用 VAE 压缩"不再理所当然：表征对齐（REPA）、表征自编码器（RAE）、像素空间扩散（JiT / DeCo / PixelDiT）三条路线并行推进。
  4. 后训练成了标配。RL（Flow-GRPO → DiffusionNFT）、奖励模型、on-policy 蒸馏，把 LLM 后训练的经验成套搬进视觉生成。
  5. 视频是主战场，并走向"世界模型"。原生音视频联合、多镜头、参考与编辑一体（Seedance 2.0、Kling-Omni、LTX-2）；自回归扩散让实时流式生成与可交互世界（Genie 3/4、Matrix-Game）成为可能。
  6. 扩散走向语言与统一多模态。掩码扩散 LLM 扩展到 100B，主打并行解码的速度；统一模型普遍"自回归管文本、扩散/流管图像"。
  7. 理论开始回答"为什么能泛化"。泛化出现得比记忆早，且记忆时间随数据量线性增长（NeurIPS 2025 最佳论文）；局部性、选择性欠拟合等解释正在拼出完整图景。

术语速查

NFE采样代价

生成一个样本需要调用网络的次数。DDPM 约 1000，DPM-Solver 约 10–20，蒸馏模型 1–8；使用 CFG 时每步通常要算两次。

噪声表 / SNR概率路径

αt,σt\alpha_t,\sigma_tαt​,σt​ 随时间的变化方式，常用信噪比 αt2/σt2\alpha_t^2/\sigma_t^2αt2​/σt2​ 描述。分辨率越高，越需要把训练时间往高噪声端移（Chen 2023、SD3）。

概率流 ODE确定性采样

与随机扩散过程具有相同边缘分布的确定性 ODE。它让"噪声 ↔ 样本"成为一一映射，因此可以反演、编辑、蒸馏。

CFG无分类器引导

训练时随机丢弃条件，采样时把有条件与无条件预测外推。几乎所有文生图 / 视频系统都在用，代价是多样性下降与过饱和（见 APG、Autoguidance）。

潜空间 / VAE在哪里扩散

用自编码器把图像压缩成潜变量，再在其上训练扩散模型。压缩率、通道数和"好不好扩散"之间存在张力（VA-VAE）。

DiT / MMDiT骨干网络

把图像切成 patch 当 token 的 Transformer 扩散骨干。MMDiT 让文本与图像 token 双流交互；单流 DiT 把它们拼成一个序列（Z-Image）。

一致性模型 / 流映射学"跳跃"

不学瞬时速度，而学从时刻 ttt 直接跳到时刻 sss 的映射 Xt→sX_{t\to s}Xt→s​。一致性模型只跳到 s=0s=0s=0；MeanFlow 学的"平均速度"等价于任意两点间的流映射。

蒸馏教师 → 学生

用多步教师训练少步学生：轨迹蒸馏（渐进蒸馏、一致性蒸馏）、分布蒸馏（DMD、SiD）与对抗蒸馏（ADD、LADD）。

奖励微调 / RL后训练

用奖励模型或规则对生成结果打分，再优化模型：可微奖励反传（ReFL、DRaFT）、偏好对（Diffusion-DPO）、在线策略梯度（DDPO、Flow-GRPO）与前向过程方法（DiffusionNFT）。

掩码扩散离散数据

用"逐步把 token 换成 [MASK]"作为加噪，训练模型并行填回。扩散语言模型（LLaDA 等）大多基于此，解码时一次可确定多个 token。

自回归扩散流式视频

帧或块之间自回归，块内做扩散；不同 token 可以处在不同噪声水平（Diffusion Forcing）。这是实时、无限长视频与交互世界模型的基础。

世界模型可交互的视频

以动作（键盘、相机、机器人指令）为条件、逐帧生成未来画面的模型，可以被"玩"或用于训练智能体（GameNGen、Genie 3）。

为什么说它们等价

给定同一族边缘分布 ptp_tpt​，噪声、数据、速度、分数四种预测之间只差线性换算；换一个噪声表，相当于对时间重新参数化并对 xxx 做缩放。所以"DDPM + 余弦表 + vvv 预测"和"流匹配"在数学上非常接近，差别主要在三处：

  1. 训练时 ttt 怎么采样、损失怎么加权：例如 SD3 的 logit-normal 时间采样、Min-SNR 加权；Kingma 与 Gao 证明这些加权都对应带数据增强的 ELBO。
  2. 预测哪个量：ε\varepsilonε 在低噪声端稳、x0x_0x0​ 在高噪声端稳、vvv 两头折中；像素空间里 xxx 预测更好（JiT）。
  3. 用 ODE 还是 SDE 采样、用几阶求解器：速度与质量的权衡。

延伸阅读：Flow Matching Guide and Code、The Principles of Diffusion Models。

ODE 与 SDE：确定性与随机性

扩散的反向过程可以写成 SDE，也可以写成具有相同边缘分布的概率流 ODE：

dx=[f(t) x−12g(t)2 ∇xlog⁡pt(x)]dt\mathrm d x=\Bigl[f(t)\,x-\tfrac12 g(t)^2\,\nabla_x\log p_t(x)\Bigr]\mathrm d tdx=[f(t)x−21​g(t)2∇x​logpt​(x)]dt

ODE 确定、可逆、适合少步与编辑；SDE 每步注入噪声，能纠正前面步骤的误差，但需要更多步。这一点在最近一年很关键：Flow-GRPO 把确定性的流匹配 ODE 改写成边缘分布不变的 SDE，才获得了强化学习需要的"随机策略"；DiffusionNFT 则绕开反向过程，直接在前向加噪过程上做优化。

二十行看懂流匹配（PyTorch 伪代码）

# 训练：一行加噪，一行回归
x0  = batch                                         # 数据（或 VAE 潜变量），形状 [B, C, H, W]
eps = torch.randn_like(x0)
t   = torch.sigmoid(torch.randn(x0.shape[0]))       # logit-normal 时间采样（SD3 的做法）
tt  = t.view(-1, 1, 1, 1)
xt  = (1 - tt) * x0 + tt * eps                      # 直线路径：t=0 是数据，t=1 是噪声
cond_in = drop(cond, p=0.1)                         # 随机丢弃条件，为 CFG 做准备
loss = ((model(xt, t, cond_in) - (eps - x0)) ** 2).mean()   # 回归速度 v = ε − x0

# 采样：从噪声出发，用欧拉法把 ODE 从 t=1 积分到 t=0
x  = torch.randn(shape)
ts = torch.linspace(1, 0, steps + 1)
for t_cur, t_next in zip(ts[:-1], ts[1:]):
    v_c = model(x, t_cur, cond)                     # 有条件预测
    v_u = model(x, t_cur, None)                     # 无条件预测
    v   = v_u + w * (v_c - v_u)                     # CFG，w 常取 3–7
    x   = x + (t_next - t_cur) * v                  # 一步欧拉

把最后一行换成二阶 Heun、把时间网格向高噪声端平移，就是大多数开源文生图 / 视频模型默认采样器的样子。

少步生成

理论

"为什么不记忆"有了更完整的答案

Bonnaire 等（NeurIPS 2025 最佳论文）指出训练中存在两个时间尺度：泛化先出现，记忆后出现，且记忆所需时间随数据量线性增长。随后的工作从多个角度补全：采样只经过的区域才被拟合（选择性欠拟合）、局部性来自数据统计（Locality）、流形假设下泛化可证地先于记忆（ETH），以及去噪器架构如何决定创造力（Hebrew Univ）。

    评测：在量什么、有哪些坑

    分布距离

    生成分布与真实分布像不像

    • FID：Inception 特征上的 Fréchet 距离，ImageNet 方法论文的主指标
    • FD-DINOv2：换用 DINOv2 特征，对扩散模型更公平
    • CMMD：CLIP 特征 + MMD，不假设高斯
    • 坑：重训与换种子带来的波动可能大于方法差距（FID 彩票）

    文图一致

    画的是不是你说的

    • GenEval：计数、位置、颜色等组合能力
    • DPG-Bench、T2I-CompBench：长提示与组合
    • TIFA、DSG、VQAScore：用问答打分
    • WISE、OneIG、UniGenBench++：知识与细粒度语义
    • 坑：GenEval 已接近饱和，且是 RL 的常用奖励，存在"刷榜"风险

    人类偏好

    好不好看、合不合意

    • ImageReward、HPSv2、HPSv3、PickScore
    • 竞技场式人类投票（LMArena、Artificial Analysis 等）是产业界最常引用的排名
    • 坑：同一个奖励既做训练目标又做评测，会高估效果（奖励投机）

    视频

    画质、运动、物理

    • PhyGenBench、VideoPhy、Physics-IQ：物理常识

    可控、一致、可交互

    日期工作类别一句话

    开放问题

    一步生成的天花板

    一步模型的 FID 已追上多步，但在文生图、视频这类开放任务上的多样性、可编辑性与可控性仍落后；"从头训练"能否扩展到十亿级尚待验证。

    潜空间该长什么样

    语义表征、重建保真、"好扩散"三者如何兼得？像素空间的成本能否在视频上接受？理解与生成能否共用一个视觉表征？

    奖励从哪里来

    标量奖励易被投机，人类偏好昂贵且主观；可验证奖励（物理、几何、文字）只覆盖少数维度。如何像 LLM 那样获得可扩展的奖励？

    长时程一致与记忆

    分钟级视频与世界模型会漂移、遗忘已见场景；显式 3D 记忆、潜空间记忆、检索式记忆各有代价。

    物理与因果

    "看起来对"不等于"物理上对"。视频模型能否成为可靠的物理模拟器与机器人训练环境？评测仍很初步。

    扩散 LLM 的定位

    并行解码带来速度优势，但质量与推理能力仍普遍略逊于同规模自回归模型；它更可能成为草稿模型、编辑器，还是独立主流？

    泛化、记忆与版权

    理论解释了平均意义上的泛化，但对单个样本是否被记住、训练数据的授权与溯源、水印的鲁棒性，仍缺乏可落地的保证。

    算力与能耗

    视频生成的推理成本远高于文本；稀疏注意力、低比特量化、少步蒸馏叠加后的质量损失如何系统评估？
