机器人操作：从行为克隆到 VLA 与世界-动作模型

让机器人用手和夹爪完成真实世界的任务，是具身智能里最难、也最受关注的方向。本页梳理学习型机器人操作的问题设定、策略架构与动作表示、VLA 基础模型、数据采集与规模化、仿真、强化学习后训练、世界模型与评测，并重点整理最近一年（2025-10 → 2026-10）的进展。

一页看懂

一句话：今天的主流做法是"预训练好的视觉语言模型 + 一个生成连续动作块的动作专家"，先在跨本体的大数据上预训练，再用少量任务数据和强化学习做后训练。十年来真正推动进展的，是三件事：更好的策略表示（能表达多峰、高频、精细的动作）、更多更杂的数据（遥操作、手持接口、人类视频、仿真），以及更可靠的评测。

2015 → 2019

端到端与自监督

端到端视觉运动策略把像素直接映射到力矩；Pinto 与 Gupta、Levine 等用数百小时机器人时间自监督学抓取；QT-Opt 做大规模离线 + 在线 Q 学习；Dex-Net 用合成数据学抓取。

2020 → 2022

模仿学习与语言条件

Transporter、PerAct 用空间结构提升样本效率；BC-Z、RT-1 把语言条件模仿学习做到数百任务；SayCan 让 LLM 做高层规划。

2023 → 2025-09

扩散策略、VLA 与数据集

Diffusion Policy 与 ACT/ALOHA 让精细双手任务可学；RT-2 提出 VLA；Open X-Embodiment、DROID 汇聚数据；OpenVLA、π0、π0.5、Gemini Robotics 成为基础模型；UMI 让采集脱离机器人。

2025-10 → 2026-10（最近一年）

后训练、十万小时数据、WAM

RL 后训练进入 VLA 工序（π*0.6、SOP）；真机数据迈向几十万小时（GEN-1、Xiaomi-Robotics-1），人类视频到百万小时（HumanNet）；世界-动作模型崛起（DreamZero）；扰动评测暴露 VLA 的脆弱（LIBERO-PRO）。

七个结论

  1. 架构基本收敛。"VLM 骨干 + 扩散/流匹配动作专家 + 动作分块"是 2025–2026 年的主流（π0 系列、GR00T、Gemini Robotics），离散 token（RT-2、OpenVLA）与连续回归（OpenVLA-OFT）作为补充；差异更多在数据配方与后训练。
  2. 数据是第一瓶颈，采集方式在迁移。遥操作 → 手持/穿戴接口（UMI 一类）→ 第一人称人类视频；单个模型的训练数据从数百小时涨到数十万小时，多家宣称看到扩展规律，但口径不一、难以复核。
  3. 后训练成为标配。RL 从仿真走向真机与机器人舰队（π*0.6、SOP、RL Token、舰队经验学习），把"示范上限"抬高到"部署中持续变强"。
  4. 世界-动作模型（WAM）崛起。从视频生成模型出发联合预测画面与动作，泛化上超过同规模 VLA（DreamZero 宣称 2 倍以上）；世界模型也开始承担策略评测与数据生成。
  5. 实时性被系统化处理。动作分块、异步推理、实时分块（RTC）与轻量化，让慢的大模型也能平滑控制，并开始处理运动中的物体。
  6. 评测正在补课。LIBERO 等仿真基准已饱和，加扰动就崩溃；分布式真机双盲评测（RoboArena）、视频世界模型评测（Veo）与更细的鲁棒性诊断正在成为新标准。
  7. 高层推理交给大模型。ER/VLM 模型负责空间推理与任务编排，前沿通用模型直接控机器人也开始有可测表现（详见 机器人 × Agent 导读）。

问题与概念：操作策略在学什么

学习型操作的核心对象是一个策略：给定观测与任务描述，输出接下来一段时间的动作。

  1. 输入观测 oto_tot​ 通常包括多视角 RGB（腕部相机 + 外部相机）、可选的深度/点云、本体状态（关节角、末端位姿、夹爪开合），有时还有触觉与力；任务用语言指令 ℓ\ellℓ、目标图像或示范视频描述。
  2. 输出：动作块现代策略一次输出未来 HHH 步的动作序列 at:t+Ha_{t:t+H}at:t+H​（HHH 常取 10–50，对应 0.5–2 秒），而不是只输出一步：
    at:t+H∼πθ(⋅∣ot, ℓ)a_{t:t+H}\sim\pi_\theta\bigl(\cdot\mid o_t,\ \ell\bigr)at:t+H​∼πθ​(⋅∣ot​, ℓ)
    动作可以是末端位姿增量、绝对关节角或夹爪指令。分块能平滑轨迹、减少复合误差，也让慢推理有了缓冲（ACT、Diffusion Policy）。
  3. 训练：行为克隆在示范数据 D\mathcal DD 上最大化动作的似然，或用扩散/流匹配损失拟合动作分布。以流匹配动作头为例：
    L(θ)=E(o,ℓ,a)∼D, t, ε[∥vθ(a(t),t∣o,ℓ)−(ε−a)∥2],a(t)=(1−t) a+t ε\mathcal L(\theta)=\mathbb E_{(o,\ell,a)\sim\mathcal D,\ t,\ \varepsilon}\Bigl[\bigl\lVert v_\theta(a^{(t)},t\mid o,\ell)-(\varepsilon-a)\bigr\rVert^2\Bigr],\quad a^{(t)}=(1-t)\,a+t\,\varepsilonL(θ)=E(o,ℓ,a)∼D, t, ε​[​vθ​(a(t),t∣o,ℓ)−(ε−a)​2],a(t)=(1−t)a+tε
    扩散/流匹配能表达"多种合理做法"的多峰分布，这是它取代均方回归的原因。
  4. 复合误差与纠正行为克隆在自己犯错后会进入示范没覆盖的状态。DAgger 让专家在学生访问的状态上补标注；今天的对应物是人在环纠正与在线 RL（HIL-SERL、π*0.6）。
  5. 频率分层大模型推理慢（1–10 Hz），动作专家快（10–50 Hz），底层控制器更快（200–1000 Hz）。"双系统"设计（Helix、GR00T N1）与实时分块执行（RTC）都是在协调这几个时间尺度。

术语速查

行为克隆（BC）模仿学习

把"观测 → 示范动作"当作监督学习。简单有效，但会累积误差；数据覆盖面决定上限。

动作分块一次输出一段

一次预测未来几十步动作，执行一部分再重新预测。平滑、抗抖动，也给推理留出时间。

VLA视觉-语言-动作模型

以预训练 VLM 为骨干、加上动作输出的策略，借网络知识理解开放指令与新物体（RT-2 提出）。

跨本体cross-embodiment

用多种机器人（单臂、双臂、移动底盘、人形）的数据训练一个策略，再适配到新机器人（OXE、X-VLA）。

遥操作数据采集

人通过主从臂、VR 或外骨骼实时操控机器人，记录观测与动作。质量高，但每小时成本高、难以扩展。

UMI 类接口不需要机器人

人手持带相机的夹爪在真实环境里操作，事后恢复位姿作为动作（UMI）。便宜、可到野外，是 2026 年十万小时级数据的主要来源之一。

共训co-training

把任务数据与其他数据（网络图文、其他本体、人类视频、仿真）按比例混合训练，防止遗忘并提升泛化。

sim2real / real2sim仿真迁移

在仿真里训练再部署到真机；或先把真实场景重建进仿真（高斯泼溅、数字孪生）再训练（RialTo）。

优势条件化RL 后训练

训练价值函数，给每段经验标上"比预期好/差"，策略以此为条件，推理时只要"好"的那一类（π*0.6 RECAP）。

世界-动作模型WAM

从视频生成模型出发，同时预测未来画面与动作；"想象"后果再行动（DreamZero）。

双系统System 2 / System 1

慢的大模型负责理解与规划，快的小模型负责连续控制（Helix、GR00T N1、Gemini Robotics 1.5）。

本体状态proprioception

关节角、末端位姿等机器人自身状态。常用，但策略可能过度依赖它而忽视视觉，反而损害泛化（研究）。

系统全景：六种主要范式

同一个"让机器人把杯子放进水槽"的任务，不同范式把问题切在不同地方。它们并不互斥，许多系统是组合。

一个 2026 年的典型训练配方

  1. VLM 预训练：网络图文 + 空间/具身推理数据（指点、轨迹、可供性）。
  2. 机器人预训练：跨本体遥操作 + UMI + 人类视频（潜在动作或手部动作）+ 仿真，与图文数据共训，防止遗忘。
  3. 任务后训练：几十到几百小时高质量示范微调。
  4. RL 后训练：真机或世界模型中的优势条件化 / 残差 RL / GRPO 式微调，加人在环纠正。
  5. 部署与回流：舰队运行、自动评测，失败与干预数据回到第 3–4 步。

训练仍是监督学习，所以能沿用大模型的训练栈；推理时固定 I=1I=1I=1，只生成"好的那一类"动作。这一思路与 LLM 中的条件化偏好训练相近，是 2025-11 之后 VLA 后训练的代表做法（π*0.6）。

最近一年（2025-10 → 2026-10）：八个趋势

后训练

VLA 进入"后训练时代"

π*0.6（2025-11）用优势条件化把示范、自主执行和人工干预统一成一个训练目标，在叠衣、装箱、做意式咖啡等任务上吞吐翻倍以上；RL Token 只在 VLA 上挂一个小 actor-critic 头，几小时在线 RL 就让关键阶段提速最高 3 倍。系统层面，SOP、Learning While Deploying、舰队经验学习把 RL 扩展到多台机器人同时在线改进。

数据

真机数据迈向十万小时量级

Generalist 宣称 GEN-0（2025-11）用 27 万小时操作数据训练并在 7B 以上看到扩展规律，GEN-1（2026-04）约 50 万小时；学术与大厂侧，LingBot-VLA 用约 2 万小时、9 种双臂构型，Xiaomi-Robotics-1 用 10 万小时以上 UMI 数据并报告随数据与模型规模持续提升。采集正在从遥操作转向手持接口（HiFi-UMI）与闭环针对性采集（RoboPocket）。

人类视频

第一人称人类视频成为主力数据源

EgoScale 用 2 万多小时带动作标签的第一人称视频训练 VLA，发现人类数据规模与验证损失呈对数线性关系；HumanNet 构建 100 万小时的以人为中心视频库，DreamDojo 用 4.4 万小时人类视频训练机器人世界模型，Dyna 宣称 DYNA-2 用 100 万小时以上人类视频训练出人到机器人的扩展规律。方法上把人手动作当作通用"动作语言"（Being-H0.5、UniT）。

WAM

世界-动作模型崛起

DreamZero（2026-02）基于 14B 视频扩散模型联合预测视频与动作，宣称泛化比 VLA 高 2 倍以上，并成为 NVIDIA GR00T N2 的基础；GE-Act 2.0、GigaWorld-Policy、InternVLA-A1.5、OpenWAM 与 Meta 的两篇工作（渐进视觉规划、原生动作先验）跟进。为降成本，ImageWAM、DeltaWAM、WAVE-0 只预测关键帧、变化量或潜在未来；产业有 1X、FLUX 3 Action。

世界模型

世界模型承担评测与数据生成

DeepMind 用 Veo 视频世界模型评测 Gemini Robotics 策略，并与 1600 多次真机评测对照（论文）；Ctrl-World 不用真机就能给策略排名，在想象中合成成功轨迹再微调，成功率提升 44.7%；GigaWorld-1 给出用世界模型做评测的路线图。物理合理性与"动作忠实"仍是难点（PhysisForcing、DreamTrue）。

实时

实时控制与动态任务

RTC 之后，实时性被拆成多个具体问题：降低对环境变化的反应延迟（FASTER）、补偿推理延迟带来的状态偏差（VLASH、DynamicVLA）、减少"走走停停"（When to Switch、VLA-Rolling）、把模型做轻（TurboVLA 在 RTX 4090 上 32 Hz）。

空间与推理

补上 3D 空间感与"想一想"

VLA 继承的 2D 视觉编码器缺乏空间感：Spatial Forcing、From Spatial to Actions 对齐 3D 基础模型特征，GAM 以 3D 定位为基础，GroundingPI、RoboTracer 做指点与轨迹推理。推理上，Recurrent-Depth VLA 用潜空间循环实现测试时计算扩展，Fast-ThinkAct 压缩思维链延迟；Google 的 ER 1.6、ER 2 与 Gemini 4 Argon 把空间推理与编排做成 API。

评测

评测危机与新协议

标准 LIBERO 上 VLA 已普遍超过 90%，但 LIBERO-PRO 在泛化设置下让它们跌到 0%，LIBERO-Plus 发现相机视角、初始状态等小扰动就能让成功率从 95% 跌到 30% 以下，LIBERO-Para 显示换个说法就失效。新协议包括分布式真机双盲评测（RoboArena）、仿真 + 真机统一榜单（RoboDojo）、可复现的低成本真机基准（VLA-REPLICA）与失败恢复评测（LIBERO-RECOVER）。

    评测：怎样判断一个策略真的好

    仿真基准

    便宜、可复现，但已饱和

    • RLBench、Meta-World、CALVIN、LIBERO：经典擂台
    • RoboCasa、BEHAVIOR-1K、RoboTwin 2.0、RoboVerse：更大、更真实
    • 坑：LIBERO 上 90%+ 已很常见，不加扰动无法区分方法

    鲁棒性诊断

    加扰动看真实泛化

    • COLOSSEUM：14 种扰动因子
    • LIBERO-PRO、LIBERO-Plus、LIBERO-Para：视角、初始状态、指令改写
    • RoboMME（记忆）、LIBERO-RECOVER（恢复）、常识保留

    仿真对真机的预测力

    仿真分数能否代表真机

    • SIMPLER：仿真排名与真机高度相关
    • Veo 世界模拟器评测、Ctrl-World、GigaWorld-1：用世界模型代替部分真机

    真机评测

    金标准，但慢且难复现

    • RoboArena：分布式、双盲、成对比较
    • AutoEval：几乎无人值守的自主评测
    • VLA-REPLICA、RoboDojo：低成本可复现与公开榜单

    报告时该写清楚的

    让数字可比

    • 每个任务的试验次数与置信区间
    • 物体、场景、初始位置是否见过
    • 是否允许重试、人工复位、干预
    • 任务完成时间与吞吐，而不只是成功率

    专题

    工业、安全、agent

    • LIBERO-Industry：工业流程约束
    • VLA 安全综述、BadWAM
    • 大模型直接当策略：Claude plays robotics、RobotWorld

    上手路线

    读一份教程，建立全景

    从 Hugging Face 的 Robot Learning: A Tutorial 入手（RL、模仿学习到 VLA，附代码）；想快速了解 VLA，读 VLA 综述 与本页"系统全景"一节。

    在仿真里跑通模仿学习

    用 LeRobot 在 ALOHA 仿真或 LIBERO 上训练 ACT 与 Diffusion Policy，比较动作分块长度、观测是否含本体状态、示范数量对结果的影响。

    上一台便宜的真机

    SO-101 一类低成本机械臂 + LeRobot 采几十条示范，训一个单任务策略；体会数据质量、相机摆放、时延带来的差别。

    微调一个开源 VLA

    在自己的数据上微调 π0（openpi）、SmolVLA 或 OpenVLA（配合 OFT 配方），并用 LIBERO-Plus 式扰动检查泛化。

    开放问题

    数据的"正确单位"

    小时数、轨迹数还是环境多样性？人类视频 1 小时值多少真机数据？扩展规律用验证损失还是真机成功率衡量？

    泛化还是记忆

    标准基准的高分在扰动下崩溃。VLA 学到的是可迁移的技能，还是训练场景的捷径？

    精细接触与力

    插拔、拧、柔性物体与工具使用仍是短板。触觉与力控怎样以可扩展的方式进入大模型？

    真机 RL 的安全与成本

    舰队级在线学习需要可靠的奖励、复位与安全边界；人工干预怎样最省？

    VLA 还是 WAM

    先懂语言再行动，还是先预测世界再行动？二者会融合成一个模型，还是分层协作？

    长时程与记忆

    做一顿饭、收拾一个房间需要记住做过什么、物体在哪；当前多数策略是马尔可夫的。

    评测的可复现性

    真机评测昂贵且难对齐；世界模型评测与真机的一致性需要在更多任务上验证。

    硬件与本体

    平行夹爪、灵巧手、人形各有取舍；跨本体迁移的上限在哪里？（见 灵巧手导读）
