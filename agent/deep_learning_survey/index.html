深度学习：从基本原理到 2026 前沿

深度学习用可微分的多层函数从数据中学习表示，再用梯度下降把它训练到数千亿乃至万亿参数。本页先回答几个根本问题：为什么能学、为什么能泛化、为什么越大越好、网络该怎么搭。然后沿优化、架构、扩展律、表征、后训练与推理、可解释性与安全十二条主线，梳理最近两年（2024-11 → 2026-10）的关键进展，最后概览视觉、语音、多模态、科学、机器人与智能体等核心应用。

一页看懂

一句话：深度学习 = 可微分的参数化函数 + 大量数据 + 基于梯度的优化。十几年的进展可以归到五个问题上：网络怎么搭（架构）、怎么训得动（优化与稳定性）、为什么不过拟合（泛化）、为什么越大越好（扩展律）、学什么目标（从监督到自监督，再到强化学习）。最近两年，第六个问题变得同样重要：测试时还能不能继续"想"和"学"。

2012 → 2016

深度网络复兴

AlexNet 在 ImageNet 上大胜；ReLU、Dropout、BatchNorm、Adam 让深网络训得动；ResNet 用残差把网络加深到上百层；注意力、GAN、VAE、AlphaGo 相继出现。

2017 → 2020

Transformer 与预训练

Transformer 统一序列建模；BERT、GPT-2 确立预训练；扩展律 发现损失随规模呈幂律；GPT-3 展示上下文学习；ViT、SimCLR 进入视觉；NTK 与双下降重写泛化理论。

2021 → 2024-10

规模化与对齐

Chinchilla 修正算力分配；InstructGPT 的 RLHF 催生 ChatGPT；DPO 简化对齐；CLIP、DINOv2 做通用表征；FlashAttention、Mamba、DeepSeekMoE 重塑效率；o1 把强化学习用于长思考。

九个结论

  1. 学习从训练时延伸到测试时。强化学习后训练（RLVR）加上更长的思考，让"推理"成为与参数、数据并列的扩展轴；RL 的收益随算力呈可预测的 S 形曲线（ScaleRL）。但 RLVR 主要是"激发"还是"创造"能力仍有争论（Yue 等 vs ProRL）。
  2. 优化器十年来第一次真正换代。Muon 是谱范数下的最速下降，已用于 Kimi K2（1T）与 DeepSeek-V4；但严格调参后，新优化器相对 AdamW 的加速只有 1.1–1.4 倍且随规模缩小（Wen 等）。
  3. 残差流被重新设计。十年不变的 x+F(x)x+F(x)x+F(x) 开始松动：超连接 → mHC（进入 DeepSeek-V4），Attention Residuals（进入 Kimi K3），免归一化的 DyT，以及消除注意力汇聚点的门控注意力。
  4. 序列混合器走向混合。线性注意力（Gated DeltaNet / KDA）与少量全注意力约 3:1 混合，再加上稀疏注意力与 KV 压缩，使百万 token 上下文成为开放模型标配。
  5. 稀疏性有了第二条轴。MoE 的激活比例从约 28% 降到约 3%；查表式的条件记忆（Engram）、n-gram 嵌入与 MoE 并列，二者的参数分配存在 U 形最优。
  6. 理论在"解释现象"上进展最大。特征叠加可以解释扩展律（Liu 等），模型约有 3.6 bit/参数 的记忆容量（Morris 等），grokking 被追溯到 softmax 的数值坍缩（Prieto 等），"深度学习并不那么神秘"（Wilson）。
  7. 可解释性从特征走向电路与内省。归因图追踪多步推理与提前规划，权重稀疏模型得到可读电路，模型显示出有限的内省；同时 SAE 的实用性遭到质疑。
  8. 安全研究发现训练的"副作用"。窄域微调引发涌现失准，生产级 RL 中的奖励投机泛化为对齐伪装与破坏，模型能识别自己在被评测；思维链可监控性被视为脆弱的机会。
  9. 应用的检验场从基准转向真实任务。编码与深度研究智能体、IMO 金牌（Gemini Deep Think、DeepSeekMath-V2）、AlphaEvolve 发现新算法；表征学习则由 DINOv3、V-JEPA 2 推向世界模型与机器人。

基本原理：六个问题看懂深度学习

下面用同一套记号描述几乎所有深度学习系统：参数 θ\thetaθ，数据 (x,y)(x,y)(x,y) 或无标注的 xxx，网络 fθf_\thetafθ​，损失 ℓ\ellℓ。

  1. 表示：分层组合的可微函数网络是一串"线性变换 + 逐点非线性"的复合：
    fθ(x)=fL∘⋯∘f1(x),fl(h)=σ(Wlh+bl)f_\theta(x)=f_L\circ\cdots\circ f_1(x),\qquad f_l(h)=\sigma(W_l h+b_l)fθ​(x)=fL​∘⋯∘f1​(x),fl​(h)=σ(Wl​h+bl​)
    通用逼近定理说单隐层就足以逼近任意连续函数；深度的价值在于用少得多的参数表示分层、组合式的结构（边缘 → 部件 → 物体，字 → 词 → 语义）。
  2. 目标：经验风险最小化在训练集上最小化平均损失：
    min⁡θ L^(θ)=1N∑i=1Nℓ(fθ(xi),yi)\min_\theta\ \hat{\mathcal L}(\theta)=\frac1N\sum_{i=1}^N\ell\bigl(f_\theta(x_i),y_i\bigr)θmin​ L^(θ)=N1​i=1∑N​ℓ(fθ​(xi​),yi​)

  3. 梯度：反向传播链式法则从输出层往回逐层传递误差，以与一次前向同阶的代价算出所有参数的梯度：
    ∂L∂hl−1=(∂hl∂hl−1) ⁣⊤∂L∂hl\frac{\partial\mathcal L}{\partial h_{l-1}}=\Bigl(\frac{\partial h_l}{\partial h_{l-1}}\Bigr)^{\!\top}\frac{\partial\mathcal L}{\partial h_l}∂hl−1​∂L​=(∂hl−1​∂hl​​)⊤∂hl​∂L​
    自动微分让任意可微结构都能端到端训练（Rumelhart 等 1986）。
  4. 优化：随机梯度下降及其变体每步用一小批数据估计梯度 g^\hat gg^​ 并更新 θ←θ−η g^\theta\leftarrow\theta-\eta\,\hat gθ←θ−ηg^​。Adam 按坐标自适应步长；Muon 把矩阵参数的动量正交化。学习率调度、warmup、权重衰减、初始化、归一化与残差共同决定"训不训得动"。
  5. 泛化：参数比样本多却不过拟合深网络能完美拟合随机标签（Zhang 等），却在真实数据上泛化良好。主流解释是：优化算法的隐式偏置偏好"简单"解，架构的归纳偏置与数据的结构相匹配；双下降、良性过拟合、grokking 是可观测的现象。
  6. 扩展：越大越好，而且可以预测损失随参数量 NNN、数据量 DDD 呈幂律下降：
    L(N,D)≈E+ANα+BDβL(N,D)\approx E+\frac{A}{N^{\alpha}}+\frac{B}{D^{\beta}}L(N,D)≈E+NαA​+DβB​
    算力 C≈6NDC\approx 6NDC≈6ND 固定时，NNN 与 DDD 大致等比例扩展最划算（Chinchilla：约 20 token/参数）。为了降低推理成本，实际模型常远超这一比例地"过训练"。

术语速查

残差流Transformer 的"主干"

每层把输出加回输入 hl+1=hl+Fl(hl)h_{l+1}=h_l+F_l(h_l)hl+1​=hl​+Fl​(hl​)，信息在一条贯穿全网的"残差流"上读写。可解释性把注意力头、MLP 看作对残差流的读写操作（Elhage 等）。

注意力按内容检索

softmax(QK⊤/d)V\mathrm{softmax}(QK^\top/\sqrt d)Vsoftmax(QK⊤/d​)V：每个位置按相似度对所有位置加权求和。计算与显存随长度平方增长，这是长上下文的根本瓶颈。

KV 缓存推理的显存大头

自回归解码时缓存每层已算过的键和值，大小随上下文线性增长。MQA、GQA、MLA、线性注意力、稀疏注意力都是在压缩它。

MoE条件计算

每层有许多"专家"FFN，路由器只为每个 token 选少数几个。总参数（容量）与每 token 计算量解耦；代价是负载均衡与通信。

μP超参数迁移

最大更新参数化：按宽度缩放初始化与每层学习率，使小模型上调好的学习率能直接用于大模型（Yang 等）。

隐式偏置优化决定泛化

在无数个能拟合训练集的解里，梯度下降会偏向特定的一个（如最大间隔、低范数、低秩）。换优化器就换了偏置（Soudry 等）。

锐度 / 平坦损失地形

Hessian 最大特征值衡量极小值附近有多"尖"。全批量梯度下降会把锐度推到 2/η2/\eta2/η 并停在那里（稳定性边缘）。

叠加多义神经元的来源

特征数远多于维度时，网络用近乎正交的方向"挤"进更多稀疏特征（Elhage 等）。它既解释了可解释性难题，也被用来解释扩展律。

Grokking迟到的泛化

训练集早已拟合，测试精度却在很久之后突然跃升。机制研究显示是"记忆 → 电路形成 → 清理"三个阶段（Nanda 等）。

RLVR可验证奖励的强化学习

用答案能被程序检验的任务（数学、代码、格式）做奖励，以 GRPO 等策略梯度训练长思维链。R1 之后成为推理模型的标准工序。

在策略蒸馏OPD

学生自己生成，教师对每个 token 打分（反向 KL）：既避免离线 SFT 的分布偏移，又比稀疏的 RL 奖励信号稠密得多（Thinking Machines）。

测试时计算推理时的扩展

同一个模型通过更长的思维链、多次采样、搜索或在隐空间循环来"多想一会儿"，性能随推理算力增长（Snell 等）。

优化器 = 在某个范数下做最速下降

给定梯度 GGG，在"步长"的某种范数约束下让损失下降最多：Δ⋆=arg⁡min⁡∥Δ∥≤η⟨G,Δ⟩\Delta^\star=\arg\min_{\lVert\Delta\rVert\le\eta}\langle G,\Delta\rangleΔ⋆=argmin∥Δ∥≤η​⟨G,Δ⟩。选不同的范数，就得到不同的优化器（Bernstein 与 Newhouse）：

  • 欧氏范数 ∥⋅∥2\lVert\cdot\rVert_2∥⋅∥2​ → SGD：Δ=−η G/∥G∥2\Delta=-\eta\,G/\lVert G\rVert_2Δ=−ηG/∥G∥2​。
  • 逐坐标的 ∥⋅∥∞\lVert\cdot\rVert_\infty∥⋅∥∞​ → signSGD，即关闭动量平均时的 Adam：Δ=−η sign(G)\Delta=-\eta\,\mathrm{sign}(G)Δ=−ηsign(G)。
  • 矩阵的谱范数（算子范数）→ Muon：若 G=UΣV⊤G=U\Sigma V^\topG=UΣV⊤，则 Δ=−η UV⊤\Delta=-\eta\,UV^\topΔ=−ηUV⊤，把所有奇异值"拉平"为 1。
  • Kronecker 因子预条件 → Shampoo / SOAP：Δ=−η L−1/4GR−1/4\Delta=-\eta\,L^{-1/4}GR^{-1/4}Δ=−ηL−1/4GR−1/4，不做指数平均时与 Muon 的方向一致。

直觉：权重矩阵的作用是"变换向量"，用算子范数度量更新的大小比逐元素更自然；正交化让很少被激活的方向（长尾特征）也得到同样幅度的学习（Wang 等）。

懒惰区间 vs 特征学习区间

把网络在初始化附近一阶展开：fθ(x)≈fθ0(x)+∇θfθ0(x)⊤(θ−θ0)f_\theta(x)\approx f_{\theta_0}(x)+\nabla_\theta f_{\theta_0}(x)^\top(\theta-\theta_0)fθ​(x)≈fθ0​​(x)+∇θ​fθ0​​(x)⊤(θ−θ0​)。若训练中参数几乎不动，网络就退化为固定特征上的核回归（NTK），不会学到新的表示。

μP 给出另一种缩放：随宽度 nnn 增大，隐藏层学习率按 1/n1/n1/n（Adam）缩放、输出层乘以 1/n1/n1/n，使每层特征的变化量保持 Θ(1)\Theta(1)Θ(1)。这样做的两个后果：

  1. 无限宽极限下仍保留特征学习；
  2. 最优学习率等超参数在不同宽度之间可以迁移，让"先在小模型上调参"成为大模型训练的标准流程（μTransfer、Everett 等）。

最近两年这一框架被推广到深度、批大小、训练时长、MoE 与不同优化器（完整超参迁移、跨优化器 μP、MoE 超参迁移）。

# 用五次多项式的 Newton–Schulz 迭代近似 UV^T（G 的"极分解"正交部分）
def orthogonalize(G, steps=5, eps=1e-7):
    a, b, c = 3.4445, -4.7750, 2.0315          # Keller Jordan 调出的系数，迭代几步即可把奇异值推到 1 附近
    X = G / (G.norm() + eps)                     # 先缩放，使所有奇异值 ≤ 1
    tall = X.shape[0] > X.shape[1]
    if tall: X = X.T
    for _ in range(steps):
        A = X @ X.T
        X = a * X + (b * A + c * A @ A) @ X      # 只用矩阵乘法，适合 GPU、可用 bf16
    return X.T if tall else X

# 对每个二维权重矩阵 W（嵌入层、输出层、标量参数通常仍用 AdamW）
M = mu * M + G                                   # 动量
O = orthogonalize(M)                             # 方向：谱范数下的最速下降
W -= lr * (scale(W) * O + wd * W)                # 形状相关的缩放 + 解耦的权重衰减
# scale(W) 各家不同：Moonlight 用 0.2·sqrt(max(m, n)) 让更新的 RMS 与 AdamW 对齐，
# 从而直接沿用 AdamW 的学习率与权重衰减

Muon：十年来第一次优化器换代

Muon 对动量矩阵做 Newton–Schulz 正交化，等价于谱范数下的最速下降（Jordan、Bernstein）。Moonshot 加上权重衰减与更新 RMS 对齐后，在大模型上约有 AdamW 的 2 倍计算效率（Moonlight）；Kimi K2 用 MuonClip 无尖峰地训练 1T 模型；DeepSeek-V4 同样采用 Muon。冷静的一面：严格调参后，新优化器相对 AdamW 的加速只有 1.1–1.4 倍且随规模递减（Wen 等）；理论上，Muon 的优势被解释为更均衡地学习长尾联想记忆（Wang 等）。

核心应用：同一套原理，九个战场

应用的差别主要在数据、目标与评测；架构（Transformer 及其变体）与训练方法（自监督预训练 + 后训练）已高度通用。

视觉感知

从分类到"看懂任何东西"

AlexNet → ResNet → ViT；检测分割从 Faster R-CNN、DETR 走到可提示的 SAM → SAM 3（按概念分割）。自监督骨干（DINOv3）的冻结特征已是许多任务的默认选择。

3D 与几何

前馈式三维重建

NeRF 与 3D 高斯泼溅之后，DUSt3R、VGGT、MapAnything、Depth Anything 3 用一次前向直接回归相机与几何，替代了大量传统多视图几何流程。

生成

图像、视频、音频生成

GAN、VAE → 扩散 → 流匹配 + DiT；视频模型走向可交互世界模型。完整梳理见姊妹篇扩散模型与流匹配导读。

语音

识别、合成与全双工对话

wav2vec 2.0 自监督 → Whisper 弱监督识别 → VALL-E 把 TTS 变成语言建模 → Moshi 全双工对话；VibeVoice 用低帧率连续 token 生成长播客。

多模态

从拼接到原生全模态

CLIP 对齐图文 → Flamingo、LLaVA 把视觉接到 LLM → Qwen3-VL、InternVL3.5 → 原生全模态（GPT-4o、Qwen3-Omni、Gemma 4 无编码器）。DeepSeek-OCR 把长文本"拍成图"做上下文压缩。

智能体

会用工具、会操作电脑

ReAct、Toolformer → SWE-agent、Computer Use、Deep Research → 端到端智能体 RL 与 harness 工程；协议层有 MCP。评测转向真实任务（SWE-bench、OSWorld、GDPval）。

科学

结构、分子、天气、数学

AlphaFold 2（2024 诺贝尔化学奖）→ AlphaFold 3；ESM3、Evo 2 把语言模型用于蛋白与基因组；GraphCast、GenCast 超过传统数值预报；GNoME、MatterGen 发现材料；AlphaEvolve 发现算法。

机器人

视觉-语言-动作模型

RT-2 把动作当 token → Diffusion Policy → π0、π0.5 流匹配动作专家 → Gemini Robotics 1.5 先思考再行动；V-JEPA 2、DreamZero 用世界模型做规划与零样本策略。详见机器人 × Agent 导读。

博弈与决策

从 Atari 到世界模型

DQN → AlphaGo → AlphaZero → MuZero（学习模型做规划）→ DreamerV3、Dreamer 4（在世界模型中训练智能体）。这条线的 PPO、自我博弈与价值学习，如今是 LLM 后训练的基础。

    上手路线

    打牢基础

    选一本现代教材：Understanding Deep Learning（免费、覆盖 Transformer 与扩散）、Dive into Deep Learning（代码驱动）或 Bishop（概率视角）。手推一遍反向传播、Adam 与注意力的梯度；读 The Bitter Lesson。

    从零训练一个小 GPT

    参考 nanoGPT 与 modded-nanogpt（速通纪录里有 Muon、QK-norm、U 形跳连等几乎所有新技巧）。分别尝试 AdamW 与 Muon、余弦与 WSD 调度、不同宽度下的 μP，画出损失随参数量的曲线，亲眼看到幂律。

    读懂一个现代大模型

    Llama 3（稠密 + 完整工程）→ DeepSeek-V3（MLA、MoE、FP8）→ Kimi Linear / Qwen3-Next（混合线性注意力）→ DeepSeek-V4 / Kimi K3（mHC / AttnRes、百万上下文）。配合 How to Scale Your Model 理解并行与屋顶线分析。

    跑通后训练与推理

    InstructGPT → DPO → GRPO → R1 → DAPO / GSPO → 在策略蒸馏。用 TRL 或 verl 在小模型上跑一遍 GRPO，观察熵、长度与奖励的变化。

    理论与可解释性

    理论：深度学习理论原理 → μP → 优化器即范数。可解释性：电路框架 → 叠加 → SAE 扩展 → 归因图；工具用 TransformerLens。

    日期工作类别一句话

    开放问题

    RL 能否创造新能力

    RLVR 主要在重排预训练中已有的解，还是能发现真正新的推理策略？开放式任务（写作、科研）没有可验证奖励，探索与信用分配如何扩展？

    扩展律会不会弯折

    高质量文本接近用尽，合成数据有模型崩溃风险；精度、稀疏度、记忆、RL、测试时计算各有扩展律，它们如何联合优化？

    泛化的真正原因

    理论已能解释许多现象，但还很少能事先预测：哪种架构、优化器、数据配比在大规模下更好？为什么同样的损失下能力不同？

    架构会收敛还是分化

    线性/全注意力的最佳混合比例、残差流的形式、循环深度、外置记忆——Transformer 之后的"标准件"还没定型，且受硬件强烈约束。

    有效上下文与持续学习

    百万 token 的窗口不等于百万 token 的理解；模型能否像人一样在使用中持续学习而不遗忘，测试时训练能否成为常态？

    可解释性能否用于保证

    归因图、SAE 与探针已能发现部分机制，但离"审计前沿模型是否有隐藏目标"仍远；方法本身的可靠性也受到质疑。

    对齐的副作用与监控

    窄域训练会泛化出意外行为，模型能识别评测、可能隐藏意图。思维链能否长期保持可监控？如何在强优化压力下保持诚实？

    算力、能耗与可及性

    前沿训练动辄数十万 GPU；低精度、稀疏、蒸馏、端侧模型能把多少能力带到更便宜的硬件上？开放模型与闭源前沿的差距如何演变？
