# 一百多年的哲学：从 1900 到今天

> 二十世纪的哲学常被说成一座“分裂的房子”：一边是英美的分析哲学，一边是欧陆的现象学、存在主义与批判理论。这份简明教程沿着时间线，把一百多年里最重要的转向、问题与人物串成一条读得懂的故事，每章只讲核心观点和一个值得记住的思想实验。

## 导读：一座分裂的房子 {#intro}

1900 年 8 月，尼采在魏玛去世；同一年，胡塞尔出版了《逻辑研究》第一卷，弗洛伊德的《梦的解析》刚刚面世，罗素正在为数学寻找一个逻辑的地基。旧的确定性在松动：上帝、理性、科学、语言，似乎都需要重新被审视。接下来的一百多年，哲学就是在回答这件事——**当一切不再理所当然，我们还能确定地知道什么、说出什么、做些什么？**

人们常说，二十世纪的哲学是一座“分裂的房子”：

- **分析哲学**（主要在英美）相信，很多哲学问题源于语言和概念的混乱，只要用逻辑把话说清楚，问题就会被解决或消解。它的风格是论证、定义、反例。
- **欧陆哲学**（主要在德法）从具体的人的经验出发，关心存在、历史、权力、意义。它的风格是描述、诠释、批判。

这个划分很粗糙——两边的源头其实是同一场危机，近几十年来也越来越多地彼此对话——但作为一张入门地图，它很好用。再加上美国本土的**实用主义**，以及战后复兴的**伦理学与政治哲学**，就是图 1 的四条主线。

## 1. 世纪之交：危机与两个“回到” {#ch1}

### 1.1 上帝死了，然后呢 {#ch1-1}

尼采在 [《快乐的科学》](https://plato.stanford.edu/entries/nietzsche/) 里借一个疯子之口宣布“上帝死了”。这不是一句无神论的口号，而是一个文化诊断：支撑欧洲两千年道德与意义的最高根据已经失效，而人们还没有意识到这件事的后果。如果没有了这个根据，价值从哪里来？真理还有没有绝对的地位？——整个二十世纪的欧陆哲学，几乎都在处理这份遗产。

### 1.2 数学与逻辑的地基危机 {#ch1-2}

另一边，数学也遇到了麻烦。弗雷格想证明全部算术可以从纯逻辑推出来；1902 年，罗素写信告诉他，他的系统里藏着一个矛盾（“所有不包含自身的集合组成的集合，包含它自己吗？”）。弗雷格的毕生事业一夜动摇。罗素与怀特海随后写出三大卷 [《数学原理》](https://plato.stanford.edu/entries/principia-mathematica/) 来修补地基；1931 年，哥德尔又证明：任何足够强的形式系统，都存在既不能证明也不能否证的命题（[不完全性定理](https://plato.stanford.edu/entries/goedel-incompleteness/)）。**逻辑的力量与它的极限，在同一代人手里被同时发现。**

### 1.3 反心理主义：分裂之前的共同起点 {#ch1-3}

当时流行一种看法：逻辑规律不过是人类思维的心理规律。弗雷格和胡塞尔都激烈反对——如果逻辑只是心理习惯，那么“2+2=4”就只是“我们碰巧这样想”，真理就失去了客观性。

有意思的是，两人从同一个起点出发，走向了相反的方向：

| | 弗雷格 → 分析哲学 | 胡塞尔 → 现象学 |
|---|---|---|
| 怎样保住客观性 | 分析**语言与逻辑**的结构 | 描述**意识中事物如何被给予** |
| 基本工具 | 形式逻辑、概念分析 | 现象学描述、本质直观 |
| 口号 | 把思想说清楚 | [回到事物本身](https://plato.stanford.edu/entries/husserl/) |

!!! analogy "一个比喻"
    两人都想为大楼重新打地基。弗雷格去检查建筑图纸的语法（语言与逻辑），胡塞尔去检查人是怎么“看见”这栋楼的（经验的结构）。两种工作都必要，但工程队从此分成了两支。

<details class="quiz"><summary><span class="qtag">自测</span>为什么说分析哲学和现象学有“共同起点”？</summary><p>二者都起源于对心理主义的反驳：都坚持逻辑与意义的客观性，不能还原为个人心理过程。区别在于，弗雷格把客观性落实在语言和逻辑形式上，胡塞尔则落实在意识对对象的意向结构上。</p></details>

## 2. 语言转向：把话说清楚 {#ch2}

### 2.1 涵义与指称 {#ch2-1}

“晨星”和“暮星”指的是同一颗星——金星。可是“晨星就是晨星”是废话，“晨星就是暮星”却是一个天文学发现。弗雷格在 [《论涵义与指称》](https://plato.stanford.edu/entries/frege/) 里解释：一个词既有**指称**（它指向的对象），也有**涵义**（指向对象的方式）。意义问题从此成了哲学的中心问题。

### 2.2 当今的法国国王是秃头吗 {#ch2-2}

法国早就没有国王了。那么“当今的法国国王是秃头”是真是假？说它真不对，说它假，似乎意味着他“不秃”，也不对。罗素在 [《论指称》](https://plato.stanford.edu/entries/russell/) 里给出了一个漂亮的分析：这句话的真实逻辑形式是“存在一个且只有一个法国国王，并且他是秃头”——第一部分为假，所以整句为假。**日常语法会误导我们，逻辑形式才揭示真相**，这成了分析哲学的方法论信条。

### 2.3 早期维特根斯坦：凡不可说的 {#ch2-3}

维特根斯坦在 [《逻辑哲学论》](https://plato.stanford.edu/entries/wittgenstein/)（1921）里提出“图像论”：有意义的命题就像一幅图画，用逻辑形式描摹世界中可能的事态。由此推出一个惊人的结论：伦理、美学、宗教、人生的意义——这些都不是事实，因而**不能被有意义地说出**，只能被“显示”。全书以一句话结尾：

> “凡不可说的，必须保持沉默。”

### 2.4 维也纳学派：清扫形而上学 {#ch2-4}

1920 年代的维也纳，一群哲学家、科学家、数学家（石里克、卡尔纳普、纽拉特等）定期聚会，把这种思路推向极端，形成了**逻辑实证主义**（[维也纳学派宣言](https://plato.stanford.edu/entries/vienna-circle/)）。他们提出**可证实性原则**：一个命题要么是逻辑真理，要么能被经验检验，否则就是**无意义的**——不是假，而是根本没说出什么。“绝对精神是无限的”“无本身在无化”，统统被判为伪命题。[艾耶尔](https://plato.stanford.edu/entries/logical-empiricism/) 把这套理论带到了英语世界。

!!! pitfall "这条原则自己可证实吗？"
    “只有可经验证实的命题才有意义”——这句话本身既不是逻辑真理，也无法用经验证实。按它自己的标准，它是无意义的。这是逻辑实证主义最著名的困境，也是它在 1950 年代后迅速衰落的原因之一。

<details class="quiz"><summary><span class="qtag">自测</span>罗素怎样处理“当今的法国国王是秃头”？</summary><p>把它分析为一个存在量化的合取：存在唯一的 x 是法国国王，且 x 是秃头。因为不存在这样的 x，整句为假；它的否定“当今的法国国王不是秃头”在“存在唯一的 x……且 x 不秃”的读法下同样为假。表面的主谓语法掩盖了真实的逻辑形式。</p></details>

## 3. 现象学与存在主义：从经验出发 {#ch3}

### 3.1 胡塞尔：回到事物本身 {#ch3-1}

你看着一个杯子，你说“我看到一个杯子”。但严格说来，落进你眼睛的只有它朝向你的一面；背面、底部、里面，你一样也没看见。可你看到的从来不是“一个侧面”，而是“一个完整的杯子”。多出来的部分从哪里来？

胡塞尔的现象学就从这类问题出发：先不急着用理论解释经验，而是**如实描述事物在意识中是怎样被给予的**。几个核心概念：

- **意向性**：意识总是关于某物的意识。看总是看着什么，怕总是怕着什么。
- **悬置**：暂时给“世界独立存在”这个日常信念加上括号——不是否认它，而是把目光从“对象是什么”转到“对象如何显现”。
- **生活世界**：晚年的胡塞尔在 [《危机》](https://plato.stanford.edu/entries/husserl/) 中指出，数学化的科学建立在我们直接活在其中的前科学世界之上，忘记了这片土壤，科学就会失去对人的意义。

### 3.2 海德格尔：我们首先是在世界之中 {#ch3-2}

胡塞尔的学生海德格尔在 [《存在与时间》](https://plato.stanford.edu/entries/heidegger/)（1927）里追问一个更古老的问题：“存在”是什么意思？他从人这种特殊的存在者——**此在**——开始。我们并不是先作为孤立的主体，再去认识外部世界；我们一开始就**在世界之中**，忙着用东西、操心事情。锤子在顺手使用时几乎“隐身”，只有坏了，才变成一个摆在眼前供人打量的物体。

海德格尔还分析了**畏**（一种没有具体对象的不安）与**向死而在**：正因为人必死，人生才有“本真”与“非本真”的区别——是活出自己的可能性，还是随波逐流地活在“常人”里。

!!! pitfall "关于海德格尔的争议"
    海德格尔 1933 年加入纳粹党并出任弗莱堡大学校长，战后对此几乎保持沉默。2014 年起陆续出版的《黑色笔记本》里有反犹段落。他的思想影响巨大，但这段历史是理解他时绕不开的一部分。

### 3.3 存在主义：存在先于本质 {#ch3-3}

二战期间与战后的巴黎，现象学变成了一种“生活哲学”。萨特在 [《存在与虚无》](https://plato.stanford.edu/entries/sartre/) 里说：人不像一把裁纸刀那样先有设计图再被制造出来——**人先存在，然后通过自己的选择成为什么样的人**。所以人是“被判定为自由的”，也要为自己的选择负全部责任；用“我只是服从命令”“我天生如此”来推卸，就是**自欺**。

- **波伏瓦**在 [《第二性》](https://plato.stanford.edu/entries/beauvoir/) 中写下“女人不是天生的，而是后天形成的”，把存在主义变成了女性主义的理论基础。
- **加缪**在 [《西西弗神话》](https://plato.stanford.edu/entries/camus/) 中直面“荒诞”：人渴望意义，世界却沉默不语。他的回答是反抗而非逃避——“应该想象西西弗是幸福的”。
- **梅洛-庞蒂**在 [《知觉现象学》](https://plato.stanford.edu/entries/merleau-ponty/) 中把身体放回哲学中心：盲人的手杖、熟练的打字手指，说明身体不是我拥有的一个物体，而是我拥有世界的方式。

### 3.4 诠释学：理解总是从“成见”开始 {#ch3-4}

海德格尔的另一个学生伽达默尔在 [《真理与方法》](https://plato.stanford.edu/entries/gadamer/) 中指出：我们读一本书、理解一段历史，从来不是从零开始，而是带着自己的传统与“前见”。理解是一场**视域融合**——不是消除成见，而是在与文本的对话中修正它。

<details class="quiz"><summary><span class="qtag">自测</span>“存在先于本质”针对的是哪种看法？</summary><p>针对“人有一个预先给定的本性或用途（来自上帝、自然或社会），人生只是去实现它”的看法。萨特认为人没有预先给定的本质，人是什么由他的选择和行动决定，因此人也必须为自己是什么负责。</p></details>

## 4. 后期维特根斯坦：意义即用法 {#ch4}

### 4.1 推翻自己 {#ch4-1}

《逻辑哲学论》出版后，维特根斯坦认为哲学问题已经解决，跑去奥地利乡村当小学教师。十几年后，他回到剑桥，开始批判自己早年的理论。死后出版的 [《哲学研究》](https://plato.stanford.edu/entries/wittgenstein/)（1953）几乎是另一位哲学家的作品。

### 4.2 语言游戏与家族相似 {#ch4-2}

早期维特根斯坦认为语言的本质是描摹事实。后期他说：看看语言实际是怎么被使用的——下命令、讲笑话、打招呼、祈祷、猜谜……这些都是不同的**语言游戏**，它们没有一个共同本质。**一个词的意义，就是它在语言中的用法。**

试着给“游戏”下定义：棋类有输赢，但抛接球没有；纸牌需要技巧，但掷骰子靠运气。找不到所有游戏共有的一个特征，只有一张交错重叠的相似之网——维特根斯坦称之为**家族相似**。很多哲学困惑，正是因为我们以为每个词背后必有一个唯一的本质。

!!! analogy "哲学是治疗"
    后期维特根斯坦说，哲学的目的是“给苍蝇指出飞出捕蝇瓶的出路”。很多哲学问题不是需要回答的问题，而是语言在“休假”时制造的混乱；把词放回它日常的用法中，问题就消失了。

### 4.3 日常语言学派 {#ch4-3}

牛津的哲学家们接过了这条路线：

- **赖尔**在 [《心的概念》](https://plato.stanford.edu/entries/ryle/) 中嘲笑笛卡尔式的心灵观是“机器中的幽灵”，认为它犯了“范畴错误”——就像参观完各个学院后问“那么大学在哪里？”
- **奥斯汀**在 [《如何以言行事》](https://plato.stanford.edu/entries/austin-jl/) 中发现，有些话不是在描述事实，而是在**做事**：“我愿意”（婚礼上）、“我道歉”、“我命名这艘船为……”。说出它们就是完成一个行为。言语行为理论后来深刻影响了语言学与法学。

<details class="quiz"><summary><span class="qtag">自测</span>“家族相似”想反对什么？</summary><p>反对“一个概念必须由所有成员共有的充分必要条件来定义”的本质主义看法。许多概念的成员之间只有交错重叠的相似，没有单一的共同本质；强行寻找本质会制造哲学困惑。</p></details>

## 5. 战后分析哲学：拆掉地基，重建大厦 {#ch5}

### 5.1 蒯因：没有不可修改的信念 {#ch5-1}

逻辑实证主义依赖一个区分：**分析命题**（凭意义就为真，如“单身汉是未婚的”）和**综合命题**（要靠经验检验）。蒯因在 [《经验论的两个教条》](https://plato.stanford.edu/entries/quine/)（1951）里论证，这个区分并没有清晰的界限。

他提出了一幅新图景：我们的全部知识像一张**信念之网**，只在边缘与经验接触。遇到反常的观察时，我们可以调整网中的任何一处——甚至逻辑和数学原则——只是通常选择改动最小的地方。哲学也不再站在科学之外为它奠基，而是科学的一部分（“自然化的认识论”）。

### 5.2 葛梯尔：三页纸的反例 {#ch5-2}

从柏拉图起，“知识”常被定义为**得到辩护的真信念**。1963 年，葛梯尔发表了一篇不到三页的论文（[葛梯尔问题](https://plato.stanford.edu/entries/knowledge-analysis/)），给出了反例。一个简化版本：

> 你看了一眼墙上的钟，显示 3 点，于是你相信现在是 3 点。事实上现在确实是 3 点——但那只钟恰好在 12 小时前停了。

你的信念是真的，也有理由，但你显然并不“知道”现在是 3 点——你只是走运。半个多世纪过去，给“知识”补上第四个条件的尝试仍没有公认的答案。

### 5.3 克里普克：形而上学的回归 {#ch5-3}

1970 年，29 岁的克里普克在普林斯顿做了三次演讲，后来出版为 [《命名与必然性》](https://plato.stanford.edu/entries/rigid-designators/)。他论证：专名（如“亚里士多德”）是**严格指示词**，在所有可能世界中都指同一个人，而不是“一捆描述”的缩写。由此推出一个惊人结论：**有些必然真理是经验中发现的**——“水是 H₂O”一旦为真，就在所有可能世界都为真。

同一时期，普特南用 [孪生地球](https://plato.stanford.edu/entries/content-externalism/) 思想实验说明“意义不在头脑中”：两个心理状态完全相同的人，一个生活在水是 H₂O 的地球，一个生活在“水”其实是 XYZ 的孪生地球，他们说“水”时指的是不同的东西。刘易斯则在 [《论世界的多元性》](https://plato.stanford.edu/entries/david-lewis/) 里大胆主张，可能世界和现实世界一样真实。被逻辑实证主义判了“死刑”的形而上学，就这样在分析哲学内部复活了。

<details class="quiz"><summary><span class="qtag">自测</span>在钟表例子里，“得到辩护的真信念”的三个条件哪个没有满足？</summary><p>三个条件都满足了：信念为真，你也有理由（看钟通常可靠）。这正是葛梯尔反例的要点——三个条件都满足，却仍然不是知识，说明这个定义不充分。</p></details>

## 6. 科学哲学：从证伪到范式 {#ch6}

### 6.1 波普尔：可证伪性 {#ch6-1}

不管观察到多少只白天鹅，都不能证明“所有天鹅都是白的”；但只要看到一只黑天鹅，就能证明它是假的。波普尔在 [《科学发现的逻辑》](https://plato.stanford.edu/entries/popper/) 里据此提出：科学理论的标志不是能被证实，而是**可以被证伪**——它冒着被经验驳倒的风险。按这个标准，爱因斯坦的相对论是科学（它做出了可能失败的预言），而某些“怎么说都对”的理论则不是。

### 6.2 库恩：科学革命的结构 {#ch6-2}

库恩在 [《科学革命的结构》](https://plato.stanford.edu/entries/thomas-kuhn/)（1962）里用科学史给出了一幅更复杂的图景。大多数时候，科学家在一个**范式**（共享的理论、方法、典型问题）里做“常规科学”，遇到反常时通常会修补而不是推翻理论。直到反常积累成危机，才发生**科学革命**：范式转换，就像从托勒密到哥白尼、从牛顿到爱因斯坦。

库恩还主张，不同范式之间存在某种**不可通约性**：它们用词的意义不同，评价标准也不同，没有一个中立的裁判。这让“科学是在一步步逼近真理”的信念第一次受到了严肃挑战。

### 6.3 之后 {#ch6-3}

- **拉卡托斯**（[科学研究纲领](https://plato.stanford.edu/entries/lakatos/)）试图调和两者：理论有一个不轻易放弃的“硬核”和一圈可以调整的“保护带”，好的纲领能预言新事实，退化的纲领只能事后修补。
- **费耶阿本德**在 [《反对方法》](https://plato.stanford.edu/entries/feyerabend/) 中走得更远：科学史上没有一条从未被打破的方法规则，“怎么都行”。

!!! pitfall "库恩不是相对主义者"
    “范式转换”常被引申为“科学只是一种社会建构、所有观点同样有效”。库恩本人明确反对这种读法：后来的范式在解决问题的能力、准确性、广度等方面通常确实更好，只是这种比较不能还原为一条机械的规则。

<details class="quiz"><summary><span class="qtag">自测</span>按波普尔的标准，“明天要么下雨，要么不下雨”是科学命题吗？</summary><p>不是。它在任何情况下都为真，不排除任何可能的观察，因此不可证伪；它是一个逻辑真理，而不是关于世界的经验断言。</p></details>

## 7. 心灵哲学：从机器中的幽灵到意识难题 {#ch7}

心灵和身体是什么关系？这个笛卡尔留下的老问题，在二十世纪下半叶因为神经科学和计算机的出现变得前所未有地紧迫。几个主要立场依次登场：

| 立场 | 心灵状态是什么 | 主要困难 |
|---|---|---|
| 行为主义 | 做出某种行为的倾向 | 忍痛不说的人仍然在痛 |
| 心脑同一论（[1950 年代](https://plato.stanford.edu/entries/mind-identity/)） | 就是某种大脑状态 | 章鱼的大脑和人很不同，它也会痛吗？ |
| 功能主义（[普特南](https://plato.stanford.edu/entries/functionalism/)） | 由因果角色定义，像软件之于硬件 | 主观感受似乎被遗漏了 |

功能主义一度成为主流：疼痛就是“由组织损伤引起、导致躲避行为与痛苦信念”的那种状态，至于它由神经元还是芯片实现，无关紧要。这直接为人工智能打开了大门——[图灵](https://plato.stanford.edu/entries/turing-test/) 早在 1950 年就提议，用一场对话游戏（图灵测试）代替“机器能思考吗”这个含糊的问题。

### 7.1 三个著名的思想实验 {#ch7-1}

- **中文屋**（[塞尔，1980](https://plato.stanford.edu/entries/chinese-room/)）：一个不懂中文的人关在屋里，按一本规则手册处理递进来的中文字条，递出的回答流利得让屋外的人以为里面有人懂中文。塞尔说：他只是在操作符号，从未理解意义——程序也一样。**语法不足以产生语义。**
- **蝙蝠**（[内格尔，1974](https://plato.stanford.edu/entries/qualia/)）：我们可以知道蝙蝠回声定位的全部物理细节，却仍然不知道“作为一只蝙蝠是什么感觉”。主观视角似乎无法被客观描述穷尽。
- **玛丽的房间**（[杰克逊，1982](https://plato.stanford.edu/entries/qualia-knowledge/)）：玛丽是视觉科学家，知道关于颜色的一切物理事实，却一辈子生活在黑白房间里。当她第一次走出房间看到红色时，她学到了新东西吗？如果学到了，物理事实就不是全部事实。

### 7.2 意识的难问题 {#ch7-2}

1995 年，查默斯把问题分成两类（[意识的难问题](https://plato.stanford.edu/entries/consciousness/)）：解释大脑如何辨别、整合信息、控制行为，是“容易问题”——难在技术，不难在原理；而**为什么这些过程会伴随着主观体验**，是“难问题”。丹尼特（[《意识的解释》](https://plato.stanford.edu/entries/consciousness/)）则认为难问题是一种错觉，解决了所有容易问题，就没有剩下什么了。这场争论至今没有结束，而大语言模型的出现让它变得更加具体（见第 11 章）。

!!! key "另一条路：具身与延展"
    1990 年代起，一批研究者（[瓦雷拉等](https://plato.stanford.edu/entries/embodied-cognition/)，[克拉克与查默斯](https://plato.stanford.edu/entries/content-externalism/)）主张认知不只发生在颅骨之内，而是由身体、环境与工具共同构成——这条路线直接继承了梅洛-庞蒂和海德格尔，是分析与欧陆传统少见的汇流点。

<details class="quiz"><summary><span class="qtag">自测</span>中文屋论证针对的是什么主张？</summary><p>针对“强人工智能”的主张：只要运行了正确的程序，计算机就真正拥有理解和心灵。塞尔并不否认机器可以模拟理解，他否认的是“仅凭符号操作（语法）就足以产生理解（语义）”。</p></details>

## 8. 批判理论与后结构主义：理性、权力与文本 {#ch8}

### 8.1 法兰克福学派：启蒙为何走向野蛮 {#ch8-1}

1923 年，法兰克福大学成立了社会研究所。一群主要是犹太裔的德国思想家（霍克海默、阿多诺、马尔库塞、本雅明等）结合马克思与弗洛伊德，发展出**批判理论**：理论的任务不只是描述社会，而是揭示其中的支配关系，服务于人的解放（[《传统理论与批判理论》](https://plato.stanford.edu/entries/critical-theory/)）。

纳粹上台后他们流亡美国。在那里写成的 [《启蒙辩证法》](https://plato.stanford.edu/entries/adorno/) 提出一个令人不安的问题：本该带来解放的理性，为什么造就了集中营？他们的回答是，启蒙理性在支配自然的过程中蜕变为**工具理性**——只问手段是否有效，不问目的是否正当。好莱坞与流行音乐构成的“文化工业”，则把人塑造成顺从的消费者。马尔库塞的 [《单向度的人》](https://plato.stanford.edu/entries/marcuse/) 后来成了 1960 年代学生运动的读物。

**哈贝马斯**作为第二代领军人物，转向了更积极的方向：除了工具理性，还有**交往理性**——人们通过不受强制的论辩达成共识（[《交往行为理论》](https://plato.stanford.edu/entries/habermas/)）。民主的正当性，就来自这种公共讨论。

### 8.2 结构主义：意义来自差异 {#ch8-2}

索绪尔在 [《普通语言学教程》](https://en.wikipedia.org/wiki/Course_in_General_Linguistics) 中指出：“猫”这个词的意义不来自它和猫之间的天然联系，而来自它与“狗”“帽”等其他符号的**差异**。语言是一个差异的系统。1950—60 年代，列维-斯特劳斯、罗兰·巴特等人把这一思想推广到神话、亲属关系、时尚、广告，形成**结构主义**：主宰意义的不是个人，而是看不见的结构。

### 8.3 后结构主义：拆解中心 {#ch8-3}

1960 年代末，一批法国思想家在结构主义基础上走得更远：

- **福柯**：知识与权力不可分。他考察疯癫、医院、监狱、性的历史，揭示“正常”与“异常”是如何被历史地制造出来的。[《规训与惩罚》](https://plato.stanford.edu/entries/foucault/) 里那座**圆形监狱**——中央塔楼可以看见每个囚室，囚犯却不知道自己是否正被看着——成了现代社会自我规训的隐喻。
- **德里达**：**解构**。文本总是依赖一组等级对立（言语/文字、男/女、理性/疯狂），解构就是显示这些对立如何不稳定、如何自我颠覆（[《论文字学》](https://plato.stanford.edu/entries/derrida/)）。
- **德勒兹**（与加塔利）：用“块茎”“欲望机器”等概念，反对一切树状的、有中心的思维（[《反俄狄浦斯》](https://plato.stanford.edu/entries/deleuze/)）。
- **利奥塔**把后现代定义为“对宏大叙事的怀疑”（[《后现代状况》](https://plato.stanford.edu/entries/lyotard/)）；**鲍德里亚**则说，在媒体时代，拟像比真实更真实（[《拟像与仿真》](https://plato.stanford.edu/entries/baudrillard/)）。

!!! pitfall "“后现代”不等于“什么都行”"
    这些思想家常被批评为相对主义和故弄玄虚（1996 年的“索卡尔事件”就是一次著名的嘲讽）。但他们的核心工作——追问看似自然的范畴从何而来、为谁服务——已经深刻地进入了社会学、文学研究、性别研究与法学。批评与借鉴最好建立在读过原文的基础上。

<details class="quiz"><summary><span class="qtag">自测</span>“工具理性”和“交往理性”的区别是什么？</summary><p>工具理性只关心用什么手段最有效地达到给定目标，目标本身是否合理不在考虑之内；交往理性关心参与者如何通过不受强制的论辩，就什么是真的、对的达成相互理解与共识。前者是阿多诺、霍克海默的诊断，后者是哈贝马斯的补救。</p></details>

## 9. 伦理学与政治哲学：重新谈论“应该” {#ch9}

### 9.1 从元伦理学出发 {#ch9-1}

二十世纪上半叶，英美伦理学主要在问一个“元”问题：“善”这个词是什么意思？摩尔在 [《伦理学原理》](https://plato.stanford.edu/entries/moore-moral/) 中提出“开放问题论证”：无论你把善定义为快乐还是别的什么，“快乐是善的吗？”总还是一个有意义的问题——所以善不能被定义为任何自然属性。逻辑实证主义则更激进：“偷窃是错的”不陈述任何事实，只是在表达“呸！偷窃！”这样的情绪（情感主义）。

### 9.2 复兴：德性、案例与行动 {#ch9-2}

1958 年，安斯康姆发表 [《现代道德哲学》](https://plato.stanford.edu/entries/anscombe/)，批评现代伦理学抽空了“义务”的基础，呼吁回到亚里士多德式的**德性伦理**：与其问“我该遵守哪条规则”，不如问“一个好人会怎么做，我想成为怎样的人”。麦金太尔的 [《追寻美德》](https://plato.stanford.edu/entries/ethics-virtue/) 把这一路线推向高潮。

与此同时，伦理学开始讨论真实世界的难题：

- **电车难题**（[富特，1967](https://plato.stanford.edu/entries/double-effect/)）：失控的电车将撞死五个人，你可以扳道让它转向，撞死另一条轨道上的一个人。你该扳吗？如果不是扳道，而是把一个胖子推下桥挡住电车呢？大多数人对两种情况的直觉不同——解释这种差异，牵出了“做”与“允许”、意图与预见的区分。
- **辛格**（[《饥荒、富裕与道德》](https://en.wikipedia.org/wiki/Famine,_Affluence,_and_Morality)）：如果你路过一个溺水的孩子，你会弄脏衣服去救；那么远方因贫困而死的孩子，和眼前的孩子有道德上的区别吗？这篇文章后来成为“有效利他主义”运动的源头之一。
- **帕菲特**（[《理与人》](https://plato.stanford.edu/entries/identity-ethics/)）用分裂人、远距传送等思想实验追问：人格同一性真的那么重要吗？

### 9.3 政治哲学：正义、自由与共同体 {#ch9-3}

- **阿伦特**从极权主义的经验出发（[《极权主义的起源》](https://plato.stanford.edu/entries/arendt/)），在审判纳粹官员艾希曼时提出“平庸之恶”：巨大的罪行可以出自一个不思考的普通人。
- **伯林**区分了两种自由（[《两种自由概念》](https://plato.stanford.edu/entries/berlin/)）：**消极自由**是免于干涉，**积极自由**是自我主宰；后者一旦被国家以“你真正的自我”之名推行，就可能变成压迫。
- **罗尔斯**的 [《正义论》](https://plato.stanford.edu/entries/rawls/)（1971）是二十世纪最有影响的政治哲学著作。

!!! analogy "无知之幕"
    设想你要为一个社会设计规则，但你不知道自己将来会出生在哪个阶层、是什么性别、有什么天赋。罗尔斯认为，在这层“无知之幕”后面，理性的人会选择：每个人都享有尽可能广泛的平等基本自由；社会经济的不平等只有在对**最不利者**最有利时才被允许（差别原则）。

罗尔斯引来了两个方向的回应：**诺齐克**（[《无政府、国家与乌托邦》](https://plato.stanford.edu/entries/nozick-political/)）从自由至上主义出发，认为只要财产是正当获得与转让的，再分配就侵犯了个人权利；**社群主义者**（[桑德尔、泰勒、麦金太尔](https://plato.stanford.edu/entries/communitarianism/)）则批评罗尔斯设想的是一个脱离一切共同体与传统的“无负担的自我”。此后，森与努斯鲍姆的 [能力进路](https://plato.stanford.edu/entries/capability-approach/)、巴特勒的 [性别理论](https://plato.stanford.edu/entries/feminism-gender/) 等，把正义的讨论扩展到发展、性别与承认。

<details class="quiz"><summary><span class="qtag">自测</span>为什么在“无知之幕”后面的人会关心最不利者？</summary><p>因为他们不知道自己会成为谁，自己完全可能就是社会中最不利的那个人。罗尔斯认为，在这种高度不确定、事关一生的选择中，理性的做法是确保最坏的处境也尽可能好。</p></details>

## 10. 实用主义：哲学回到行动 {#ch10}

美国本土诞生的实用主义，比分析哲学和存在主义都更早，也在二十世纪末迎来了复兴。

### 10.1 观念的“兑现价值” {#ch10-1}

皮尔士在 [《如何使我们的观念清楚》](https://plato.stanford.edu/entries/peirce/) 里提出：一个概念的意义，就在于它对行动可能产生的全部实际效果。“硬”的意思是“很多东西都划不动它”；如果两个观念在任何可想象的实践中都没有区别，它们就是同一个观念。

**詹姆斯**（[《实用主义》](https://plato.stanford.edu/entries/james/)）把这一原则用到真理上：真观念就是那些我们能吸收、验证、并且在经验中“行得通”的观念。**杜威**则把它带进教育与民主（[《民主主义与教育》](https://plato.stanford.edu/entries/dewey/)）：知识不是对世界的静观，而是解决问题的工具；学校应该“从做中学”，民主不只是一种政体，而是一种共同生活的方式。

!!! pitfall "实用主义不是“有用就是真”"
    詹姆斯的一些说法确实容易被读成“对我有好处的就是真的”，罗素就这样批评过他。但实用主义的核心是：真理与探究、检验、经验的长期后果相连，而不是与个人一时的方便相连。皮尔士为了和这种通俗化划清界限，甚至把自己的立场改名为“实效主义”。

### 10.2 新实用主义：放下“自然之镜” {#ch10-2}

1979 年，罗蒂在 [《哲学与自然之镜》](https://plato.stanford.edu/entries/rorty/) 里宣布：从笛卡尔到分析哲学，哲学一直把心灵或语言想象成一面映照自然的镜子，并试图检验这面镜子是否准确——这个计划应该被放弃。知识不是“表象”与“实在”的对应，而是我们在对话中能够为之辩护的东西。罗蒂同时援引杜威、后期维特根斯坦、海德格尔与德里达，成为少数在分析与欧陆两边都有读者的哲学家。

<details class="quiz"><summary><span class="qtag">自测</span>按皮尔士的实用主义准则，怎样判断两个理论“其实是同一个理论”？</summary><p>看它们在一切可以设想的实际情境中是否导出不同的可观察后果或不同的行动。如果在任何经验与实践中都没有区别，那么它们的差别只是字面的，意义上是同一个。</p></details>

## 11. 今天的哲学：几条正在进行的线索 {#ch11}

### 11.1 分裂的房子在打通 {#ch11-1}

“分析 vs 欧陆”的对立在今天已经松动了很多。分析哲学家研究海德格尔与胡塞尔，现象学被用于认知科学；欧陆传统内部也越来越重视论证的清晰。真正的分界线，更多地变成了**问题**而不是**流派**。

### 11.2 人工智能把老问题变成了新问题 {#ch11-2}

图灵测试、中文屋、意义与理解、意识难题——这些曾经纯属思想实验的问题，在大语言模型出现后变得具体而紧迫（[人工智能哲学](https://plato.stanford.edu/entries/artificial-intelligence/)）：

- 只通过预测文本训练出来的模型，算不算“理解”了语言？词语的意义需要与世界、身体、行动相连吗？（后期维特根斯坦与塞尔在这里重新相遇。）
- 什么样的证据能表明一个系统有或没有主观体验？如果无法确定，我们应当怎样对待它？
- 早在 1972 年，德雷福斯就引用海德格尔与梅洛-庞蒂批评符号主义 AI（[《计算机不能做什么》](https://plato.stanford.edu/entries/artificial-intelligence/)），认为人类的大部分智能是身体性的、熟练的、不可形式化的。今天的具身智能与机器人研究，某种程度上就是在回应这一批评。

### 11.3 其他活跃的方向 {#ch11-3}

- **实验哲学**（[实验哲学](https://plato.stanford.edu/entries/experimental-philosophy/)）：用问卷和实验检验普通人的哲学直觉，发现直觉会受文化、语境、措辞的影响——这对依赖直觉的思想实验方法提出了挑战。
- **跨文化与全球哲学**：以西田几多郎（[《善的研究》](https://plato.stanford.edu/entries/kyoto-school/)）为起点的京都学派，把禅与德国哲学结合；二十世纪的中国哲学家（如冯友兰、牟宗三）则在与西方哲学的对话中重建中国思想的体系。“哲学史”不再只有一条欧洲的主线。
- **应用与公共哲学**：气候伦理、动物伦理、技术伦理、数据与隐私——哲学越来越多地直接参与公共决策。

!!! key "一百年后回看"
    二十世纪开始于对确定性的寻找：弗雷格想要逻辑的确定，胡塞尔想要经验的确定，维也纳学派想要科学的确定。一百年后，几乎每一条路线都发现了自己的界限——不完全性、不可通约性、意识的难问题、理解的不可形式化。但这些界限本身，就是这一百年最重要的发现。

## 12. 阅读路线 {#ch12}

### 12.1 先读什么 {#ch12-1}

不必从大部头开始。下面这些原著篇幅短、可读性强，适合作为入门：

| 主题 | 入门原著 | 篇幅 |
|---|---|---|
| 存在主义 | 萨特《存在主义是一种人道主义》、加缪《西西弗神话》 | 一个下午 |
| 科学哲学 | 库恩《科学革命的结构》 | 一周 |
| 心灵哲学 | 内格尔《成为一只蝙蝠是什么样子？》、塞尔《心灵、大脑与程序》 | 各一小时 |
| 知识论 | 葛梯尔的三页论文 | 十分钟 |
| 伦理学 | 辛格《饥荒、富裕与道德》 | 一小时 |
| 政治哲学 | 伯林《两种自由概念》、罗尔斯《正义论》第一章 | 一个周末 |
| 语言哲学 | 罗素《论指称》 | 一个下午 |

### 12.2 再往深处走 {#ch12-2}

- **想读分析哲学的骨架**：弗雷格、罗素 → 维特根斯坦《哲学研究》 → 蒯因 → 克里普克《命名与必然性》。
- **想读欧陆哲学的骨架**：胡塞尔的入门讲演 → 海德格尔《存在与时间》导论部分 → 梅洛-庞蒂《知觉现象学》前言 → 福柯《规训与惩罚》。
- **找二手材料**：斯坦福哲学百科（SEP）的条目由该领域的专家撰写并定期更新，是最可靠的免费入口；本页每个书名链接都指向相应条目。

!!! analogy "最后一句"
    梅洛-庞蒂说：“真正的哲学，就是重新学会看世界。”读哲学史的意义，也许不在于记住谁说了什么，而在于借一百多年里最聪明的那些眼睛，把熟悉的世界重新看一遍。
