新主页 · 四个方向的草稿

同一份内容、四种性格。每个版本都把 selected publications 做成了“一眼看懂”的动态示意（目前是代码画的占位动画，换上真实 demo 视频/GIF 即可），并补上了研究脉络、动态、长文、近况等简历之外的信息。点开任一版本，右下角浮条可以随时切换对比。

V1 · Control Room technical hardcore

深色控制台 / HUD 风格。首屏是一个可以直接打字指挥的人形机器人沙盒（呼应 TextOp），带实时关节遥测。论文是“实验日志”，新闻是 changelog。

  • 最“硬核”、最有记忆点
  • 风险：偏冷，审美偏工程师
打开 V1 →

V2 · Research Review researcher · taste

杂志 / 期刊排版：大号衬线字、朱红印章“谢炜基”、带脚注的研究陈述长文（把五篇工作串成一条线），每篇论文是一个大图专题。

  • 最有“研究者气质”和个人品味，叙事感强
  • 风险：信息密度略低，需要好的真实 demo 图撑场
打开 V2 →

V3 · Research Atlas innovative · clear

现代、明亮的产品化风格。可交互的研究地图（按方向分泳道的时间线，悬停看论文之间的继承关系，点泳道筛选），bento 速览格，论文卡片悬停播放 demo。

  • 信息最全、最好扫读，招生/合作方最友好
  • 风险：风格相对“常见”，个人味靠内容
打开 V3 →

V4 · Notebook creative · open-mind

方格纸实验笔记本：手写批注、拍立得照片、中英一键切换。每篇论文附“背后的故事”，另有“反复在想的问题”、书架、写给入门者的长文。

  • 最有人味、最体现 open-mind 和哲学兴趣
  • 风险：手写风不够“正式”，需要拿捏
打开 V4 →

说明

占位内容：论文 demo 是程序化动画（shared/demos.js）；“Now”、书架、论文背后的故事、部分新闻日期、TL;DR 措辞都是我先写的草稿，需要你改成真实的。所有内容集中在 shared/data.js，改一处四个版本同步。

换真实素材：把视频/GIF 放到 agent/new-gitpage/media/，在 data.js 对应论文填 media: "../media/xxx.mp4"。

混搭也可以：比如 V2 的排版 + V1 的交互沙盒 + V3 的研究地图。选定方向后再精修、接入 Jekyll、替换主页。
