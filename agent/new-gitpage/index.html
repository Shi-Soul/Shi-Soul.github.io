我的推荐

  1. V5 Lab Badge：证件照放在工牌上最自然，个人味和记忆点都强，信息量也最克制。现在这张照片就能直接用。
  2. V1 Control Room：最“硬核”，首屏可以打字指挥机器人，直接呼应 TextOp。
  3. V6 Swiss：最正式、最干净，适合偏学术的观感，也能直接用证件照。

换了生活照之后，V2 / V3 / V4 会好看很多；V7 适合喜欢极客趣味的话做备选。

照片建议

现在的证件照适合 V5 / V6 / V7（工牌、证件格式、像素化）。其他版本建议换一张，按优先级：

  1. 和机器人的合影：实验室里站在 G1 旁边，半身、自然光、表情放松。最贴合研究方向，也能直接当首屏大图。
  2. 工作中的抓拍：调机器人、拿着遥控器、在白板前推公式。体现 hands-on 和 technical hardcore。
  3. 户外/校园的生活照：柔和光线、背景简单、人不必居中，留出一侧空间方便排版。
  4. 有趣一点的：模仿机器人做同一个功夫动作的对比照，很适合 V1 / V4。

规格：长边 ≥ 1500px，横版、竖版各一张（横版做首屏，竖版裁头像），不要重滤镜。
