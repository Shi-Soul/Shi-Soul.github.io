# 机器人评测汇总：资料范围

- 问题：给定机器人结构、任务和评测条件，选择哪些基准，记录哪些指标？
- 读者：需要设计实验、比较策略与分析失败原因的机器人研究者。
- 检索截止：2026-10-26。
- 分析单位：有独立任务定义或评测协议的基准版本；跨本体套件按已公开的配置描述。
- 覆盖含义：覆盖结构和任务类别，不声称穷尽全部论文。

## 收录范围

从本地《具身智能／机器人 × Agent》和《灵巧手算法》综述的评测章节与参考文献出发，补充单臂、双臂、导航、移动操作和双足控制的原始资料。收录闭环仿真、实机评测和具身推理诊断；标明离线问答与数据集不能直接证明控制能力。仅有方法演示而没有可辨识评测协议的项目不作为独立基准。

原始论文、官方代码和项目页用于核对事实。本地综述用于发现线索；无法核对的条目独立列为待核实，不补写缺失信息。年份对应所引用版本，不自动等同于会议年份。

## 对比维度

1. 末端结构：夹爪、多指灵巧手、无操作末端、未限定。
2. 上肢：单臂、双臂、无机械臂、套件内多种配置。
3. 基座：固定、轮式移动、双足、四足、虚拟代理。
4. 任务：抓取放置、接触装配、铰接操作、手内操作、双手协作、导航、移动操作、运动控制、推理规划、安全。
5. 环境：仿真、实机、仿真与实机、离线。
6. 难度：按步骤长度、接触精度、感知不确定性、泛化与失败恢复列出要求。页面层级是编辑归类，不是原作者的统一难度分数。
7. 观测、动作接口、任务规模、指标、训练测试划分与可比性条件。
