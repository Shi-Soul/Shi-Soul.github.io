# 机器人评测汇总页

页面发布到 `https://shi-soul.github.io/agent/evaluation/`，沿用本站机器人综述的配色和排版。40 个条目来自本地具身智能与灵巧手综述，并经原始论文或官方资料核对。检索截止日期为 2026-10-26。

页面按末端、上肢和基座独立筛选，结构条件必须匹配同一套配置。还可筛选任务、难度来源、评测形式与仿真／实机条件，按首发或更新日期排序，比较三项基准并导出 CSV。筛选和所选比较项保存在网址参数中。

## 文件与维护

- `benchmarks.json` 保存内容、配置组合、日期、技术来源与日期来源。
- `index.html` 保存分类说明、实验组合及报告规范；`evaluation.js` 实现筛选、比较和导出；`evaluation.css` 保存响应式布局与深色主题。
- `research/` 保存收录范围、来源记录、论断证据和参考文献。
- `scripts/catalog.mjs` 检查条目、日期与链接格式，并从完整数据重新生成三份证据文件。

修改条目后，在网站仓库根目录执行：

```sh
node agent/evaluation/scripts/catalog.mjs
node --check agent/evaluation/evaluation.js
```

随后使用本地静态服务器打开页面，检查筛选、日期排序、比较、导出和手机布局。提交到网站发布分支后，GitHub Actions 使用 Node.js 静态打包脚本部署；阅读目录会自动收录此页。

## 日期规则

首次公开优先取 arXiv 的首次提交；明确版本采用官方发布日。更新日期须写明是论文修订、版本发布、数据功能更新还是榜单更新。只有初版的论文保留初版日期并标为“仅初版”；没有更新时间的来源使用空日期和“未注明”，排序时排在末尾。

arXiv 日期保留 UTC 提交记录。当前论文版本与技术引用一同核对；论文修订不表示代码也在同日更新。本页核对日期独立保存，不能替代来源更新日期。ERQA 条目明确采用关联报告首发日期，不推断代码公开日。

## 验证范围

2026-10-26 已逐项检查 40 个条目的详情、来源和日期；浏览器验证覆盖全部筛选选项、结构组合、日期排序、三项比较上限、网址恢复、CSV 导出和页内跳转。已检查 390、768、1024、1440 像素宽度及浅色／深色显示，未发现页面级横向溢出或 JavaScript 异常。

文献技能的审计脚本用于 LaTeX；它可检查此页的 40 条来源和参考文献，但会因没有 `.tex` 文件退出。网页内容及证据文件使用本目录的检查脚本和浏览器检查验证。
