02 / 分类依据

本体要拆开看，难度要说明来源

机器人本体指执行任务的机械结构。夹爪、单臂和移动底盘可以出现在同一台机器人上，因此采用三个独立维度。

A

末端：怎样接触物体

夹爪通过开合夹持；灵巧手用多个关节控制手指，可改变接触位置和抓型。

“无操作末端”表示该评测不控制抓取末端；“未限定”表示协议未绑定一种末端结构。

B

上肢：怎样协同操作

单臂／双臂记录参与操作的机械臂。两只手有时只有可移动的手腕模型，需要与完整双臂区分。

双臂任务还须区分独立操作、交接，以及共同约束同一物体。

C

基座：怎样到达工作位置

固定、轮式移动、双足、四足承担不同的运动约束。双足操作还要维持支撑与平衡。

有轮子不代表任务测试导航；人形上身不代表测试双足。目录按实际评测配置标注。

05 / 记录结果

成功率之外，还要记录什么

以下报告规范是本页的建议。基准规定的官方指标应原样保留，追加指标单独列出。

完成与进度

报告成功次数和有效试验总数，再给成功率及置信区间。超时、碰撞、求助和重置都要保留记录。完整任务成功与子任务进度分开，注明成功判定是否要求持续保持目标状态。

例如 BEHAVIOR 的 Q-score 给目标条件部分得分；CALVIN 记录连续任务链长度。两者不能换算成同一种成功率。

时间与资源

分别记录物理执行时间、模型推理等待和总耗时。报告动作频率、每次预测包含的动作数、重新观测频率，以及模型调用和推理消耗。

RobotWorld 会在代理推理时暂停仿真；这种条件须与连续运行的真实机器人区分。

泛化与恢复

分别留出物体实例、类别、场景、指令和本体。执行中施加扰动时，记录触发条件、幅度与可用恢复时间，同时报告初次成功率、恢复成功率和人工干预次数。

训练中见过新场景的示范，与完全未见场景的测试应分开。

物理质量

操作任务记录掉落、滑移、位置误差和接触力；运动任务记录跌倒、速度跟踪和碰撞。只汇总成功试验会隐藏失败代价，应同时报告全部试验与成功试验的统计。

指标必须有单位、采样方式和阈值；安全问答准确率不能代替这些物理记录。

指标与术语说明
闭环／开环执行
闭环策略用动作后的新观测修正后续动作。开环轨迹执行期间不据新观测重新规划；机器人内部仍可有位置伺服。
本体状态／特权状态
本体状态是机器人自身的关节位置、速度等信息。特权状态是评测中额外提供、实际部署传感器不能直接取得的真值，例如精确物体位姿。
RGB-D 与自由度
RGB-D 同时包含彩色图像与深度。自由度是描述可独立变化运动所需的变量数量；关节数和执行器数不必相同。
分布内／分布外
前者使用训练设定覆盖的对象与条件；后者在明确留出的对象、场景、指令或本体上测试。须写明具体留出了什么。
置信区间
由抽样方法构造的参数估计区间。95% 的含义是：在重复抽样下，该构造方法有 95% 的覆盖率；应注明计算方法与独立抽样单位。
SPL
每次试验将成功指示值乘以“最短路径长度除以实际路径与最短路径的较大值”，再求平均。它同时考虑导航是否成功和路径是否绕远。
Recall@K、RMSE、接触区域交并比
Recall@K 记录正确目标是否进入前 K 个检索结果；RMSE 是误差平方的均值再开平方根；接触区域交并比是预测与真值接触区域的交集面积除以并集面积。
DTW 与 Fréchet 距离
DTW 允许时间轴对齐后比较序列差异。Fréchet 距离在保序遍历两条曲线的所有对应方式中，取最大对应点距离的最小值。

06 / 可追溯资料

时间口径与来源

三个日期分别表示什么

首次公开优先采用 arXiv 首次提交日期；明确的基准版本以官方发布日为准。会议年份另有含义，不能代替首发日期。

来源更新记录论文最后修订或官方明确标注的版本／文档更新，并注明类型。论文只有初版时显示“仅初版”；未披露时显示“未注明”。arXiv 日期按其 UTC 提交记录保留。

本页核对是检查资料的日期。本次为 2026-10-26，不表示每个项目在这一天更新。

收录和证据边界

本体标签限定到条目描述的评测配置；框架支持范围另行说明。难度分类、评测组合和追加报告规范属于本页的整理判断。训练数据集、模拟器和方法演示不自动作为独立闭环基准收录。
