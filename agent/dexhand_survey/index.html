六个判断

  1. 你的 sim2real 工具箱可以直接迁移。域随机化、教师-学生、RMA、执行器网络在灵巧手上都有成熟对应（HORA、DexNDM、Force-Based Sim2Real）。
  2. "重定向 + 跟踪 RL"是最快的切入点。ManipTrans、DexMachina、SPIDER、REGRIND 的流程和人形运动模仿几乎一样。
  3. 数据的瓶颈是"力不对"。人类视频与遥操作的运动学数据很多，但缺接触力和触觉；2026 年的重定向开始保接触结构、追踪接触力。
  4. 基于模型的方法仍有位置。采样 MPC 与接触感知优化不用训练、可解释，正与 RL 分层结合（高层 RL 选接触点，低层 MPC 推物体）。
  5. VLA 覆盖了高自由度手，但手指接触协调仍靠低层控制器。GR-Dexter、XL-VLA、Dexora 之下，仍需要 DexterityGen、TacBPM 这类基础控制器或先验。
  6. agent 擅长自动化"奖励-环境-数据-调参-评估"循环，不擅长替代 30–500 Hz 的手指接触控制。

四个本质差异

被控对象不受驱动

要控制的是物体状态，物体没有执行器，只能经由间歇接触施力：欠驱动的混合系统，接触模式切换比步态更频繁、组合更多。

接触多且小

力、尺寸、速度都小，摩擦、滑移、柔顺性影响更大；仿真接触参数的误差相对更致命。

感知被遮挡

物体常被手挡住，视觉位姿难估；触觉因此关键，但触觉仿真很难。

硬件不统一

腱、连杆、直驱并存，自由度 6–22 不等，没有统一平台，跨本体表示因此成为独立方向。

泛化维度也不同：腿足主要泛化地形，灵巧手主要泛化物体（形状、质量、摩擦、铰接结构）。

开放问题

力与接触数据从哪来

人类视频与遥操作缺力和触觉；仿真补全、力感知重定向、真实特权传感器三条路尚未收敛。

执行器与接触参数

腱、回差、指尖材料让关节级建模成为必需，需要像腿足 actuator net 那样的标准流程。

触觉标准化

每种传感器都像一台新机器人；SBLR、Tactile Genesis 在尝试统一抽象。

跨本体

6–22 DoF、不同驱动的手能否共享策略？规范 URDF、潜在动作空间是候选答案。

长时程与工具

魔方、铰接工具、拧螺丝要"保持一部分接触、同时改变另一部分接触"，策略组合与接触规划仍难。

评测

真机任务难复现；仿真基准在推进，但缺少分布式的真机评测。

agent 的边界

大模型能否在 10–100 Hz 的环里做触觉纠正？目前只在慢速、离散的决策上有效。

评估器与安全

编码 agent 自动训练需要可靠的自动判定与真机安全流程，否则会"优化评估器的漏洞"。

MuJoCo Playground 论文 · ViserDex

把你的 sim2real 工具箱搬过来

执行器建模（DexNDM、电流-力矩标定）、RMA 式适应（HORA）、视觉位姿（ViserDex）、预训练先验（ADEPT）。

选硬件

入门可选 LEAP Hand（低成本）或 ORCA（开源）；要做力控与触觉，看直驱 + 触觉的商用手（Sharpa Wave、Wuji 等），先确认 MuJoCo / URDF 资产与电流-力矩接口。

数据与模仿

AnyTeleop 或 Vision Pro 遥操作（Bunny-VisionPro）；"重定向 + 跟踪 RL"可从 DexMachina 或 ManipTrans 的配方入手，流程和人形运动模仿几乎一样。

加入 agent

让编码 agent（Claude Code / Codex）照 Eureka、Text2Touch 的方式写奖励，或照 GenDexHand、DexAgent 的方式生成环境与数据；低层控制仍由你训练的策略或 MPC 负责。真机前务必有限位、急停与人工确认。
