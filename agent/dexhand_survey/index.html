八个判断

  1. 你的 sim2real 工具箱可以直接迁移。域随机化、教师-学生、RMA、执行器网络在灵巧手上都有成熟对应（HORA、DexNDM、Force-Based Sim2Real）。
  2. "重定向 + 跟踪 RL"是最快的切入点。ManipTrans、DexMachina、SPIDER、REGRIND、CHORD 的流程和人形运动模仿几乎一样。
  3. 数据的瓶颈是"力不对"。人类视频、遥操作和合成数据都在放大，但运动学数据缺接触力和触觉；2026 年的重定向开始保接触结构、追接触力（TopoRetarget、ReForce、CHORD）。
  4. 真机 RL 在灵巧手上开始可用。人在环（HIL-SERL）、残差（ResFiT、BORA）、MPC 脚手架把真机探索的风险和时间压到可接受范围。
  5. 基于模型的方法仍有位置。采样 MPC 与接触感知优化不用训练、可解释，并与 RL 分层结合（高层 RL 选接触点，低层 MPC 推物体）。
  6. 触觉进入"基础模型 + 世界模型"阶段。Sparsh、AnyTouch 做表征，TacSL、UniVTAC 做仿真，DexTacWAM 等把触觉当作要预测的世界状态。
  7. VLA 覆盖了高自由度手，但手指接触协调仍靠低层控制器与后训练。GR-Dexter、XL-VLA、Dexora 之下，仍需要 DexterityGen、TacBPM 这类基础控制器。
  8. agent 擅长自动化"奖励-环境-数据-调参-评估"循环，不擅长替代 30–500 Hz 的手指接触控制。

四个本质差异

被控对象不受驱动

要控制的是物体状态，物体没有执行器，只能经由间歇接触施力：欠驱动的混合系统，接触模式切换比步态更频繁、组合更多。

接触多且小

力、尺寸、速度都小，摩擦、滑移、柔顺性影响更大；仿真接触参数的误差相对更致命。

感知被遮挡

物体常被手挡住，视觉位姿难估；触觉因此关键，但触觉仿真很难。

硬件不统一

腱、连杆、直驱并存，自由度 6–22 不等，没有统一平台；跨本体表示（OHRA、UHAS、XL-VLA、UniDexTok、DexFormer）因此成为独立方向。

泛化维度也不同：腿足主要泛化地形，灵巧手主要泛化物体（形状、质量、摩擦、铰接结构）。

配方速查：灵巧手 RL / 模仿的默认清单

2022–2026 年大量工作共享的做法，可以当作搭第一个灵巧任务时的检查表。

观测

  • 本体：关节位置及若干帧历史、上一步动作。
  • 物体：位姿、点云或关键点。TriFinger 的工作发现，用关键点表示物体位姿（观测和奖励都用）比位置 + 四元数更好。

  • 教师额外拿特权信息：质量、摩擦、质心、形状参数、真实接触。

常见坑

  • 仿真碰撞体与真实指垫的形状、厚度不一致；连杆手的耦合关节在仿真里没建模。
  • PD 增益与执行器饱和不一致；长时间运行后电机发热，特性随之漂移。
  • 仿真与真机的触觉接触事件对不上（Blind Dexterous Grasping 专门做了 Real2Sim 接触事件标定）。
  • 遮挡导致物体位姿抖动；训练物体集合过于规则。

开放问题

力与接触数据从哪来

人类视频与遥操作缺力和触觉；仿真补全、力感知重定向、真实特权传感器、力反馈遥操作四条路尚未收敛。

执行器与接触参数

腱、回差、指尖材料让关节级建模成为必需，需要像腿足 actuator net 那样的标准流程。

触觉标准化

每种传感器都像一台新机器人；触觉基础模型与统一仿真（UniVTAC、Tactile Genesis）在尝试统一抽象。

跨本体

6–22 DoF、不同驱动的手能否共享策略？规范 URDF、潜在动作、图表示是候选答案。

长时程、工具与可变形物体

魔方、铰接工具、衣物要"保持一部分接触、同时改变另一部分接触"，策略组合与接触规划仍难。

真机 RL 的安全与效率

人在环、残差、MPC 脚手架是目前最有效的组合，但还缺通用的安全约束与自动复位方案。

评测

仿真基准快速增加（DexVerse、HandsOn、BiDex-100），但真机任务难复现，缺少分布式的真机评测。

agent 的边界与评估器

大模型目前只在慢速、离散的接触决策上有效；编码 agent 自动训练需要可靠的自动判定，否则会"优化评估器的漏洞"。
